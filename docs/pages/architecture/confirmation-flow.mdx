# Confirmation Flow

Two-step transaction pattern for safety.

## Overview

All state-changing operations require explicit confirmation:

```
1. Tool call → Preview + Token
2. User reviews preview
3. confirm-action → Execute
```

## Why Confirmation?

- **Prevent accidents**: Can't execute without review
- **Preview details**: See amounts, fees, warnings
- **Token expiry**: Time-limited authorization
- **Audit trail**: Clear action/confirmation separation

## Implementation

### Creating Pending Transaction

Transaction tools call `handleTransactionWithElicitation()`, which stores the
pending transaction with an `elicitationSummary` attached. The summary is shown
to the user at confirm time via MCP elicitation.

```typescript
// Simplified from handleTransactionWithElicitation()
const { summary, chain, preview, execute, tip } = params;

// Format preview for elicitation display at confirm time
preview.summary = summary;
const elicitationSummary = formatPreviewForElicitation(preview);

// Store pending with elicitation summary attached
const confirmationToken = storePending(
  summary,
  chain.chainId,
  execute,
  undefined,          // preValidate
  elicitationSummary, // shown at confirm time
);

return buildTxResponse({
  status: "pending_confirmation",
  summary,
  chain: chain.chainId,
  preview,
  confirmationToken,
  tip,
});
```

### Confirming Transaction

When `elicitationSummary` is present on the pending entry, `confirm-action`
shows an MCP elicitation form to the user before executing.

```typescript
server.registerTool(
  "confirm-action",
  {
    description: "Execute a pending transaction",
    inputSchema: { confirmationToken: z.string() },
  },
  async ({ confirmationToken }) => {
    const pendingEntry = pending.get(confirmationToken);
    if (!pendingEntry) {
      throw new Error("Invalid or expired confirmation token");
    }

    // Elicitation gate: require user confirmation via form
    if (pendingEntry.elicitationSummary) {
      if (!supportsFormElicitation(server)) {
        return { /* error: client does not support elicitation */ };
      }
      const result = await requestTxConfirmation(
        server,
        pendingEntry.elicitationSummary,
      );
      if (!result || !result.confirmed) {
        return { status: "cancelled", message: "Transaction cancelled by user" };
      }
    }

    // Execute
    const result = await executePending(confirmationToken);
    return {
      content: [{
        type: "text",
        text: JSON.stringify({
          status: "success",
          txHash: result.txHash,
          suggestedActions: [
            { tool: "get-transaction-status", reason: "Track status", priority: 1 }
          ]
        }, null, 2)
      }]
    };
  }
);
```

## Preview Structure

```typescript
interface TransactionPreview {
  summary: string;           // Human-readable description
  from: string;              // Sender address
  to: string;                // Recipient address
  amount: {
    value: string;
    denom: string;
    formatted: string;
  };
  estimatedFee: {
    value: string;
    denom: string;
    formatted: string;
  };
  warnings?: Warning[];      // Any cautions
}

interface Warning {
  level: "info" | "warning" | "danger";
  message: string;
}
```

## Token Management

### Configuration

```bash
KEPLR_TX_TTL_MINUTES=5  # Default: 5 minutes
```

### Token Structure

```typescript
interface PendingAction {
  summary: string;                            // Human-readable description
  chain: string;                              // Chain ID
  execute: (ctx?) => Promise<unknown>;        // Execution function
  preValidate?: (ctx?) => Promise<void>;      // Pre-execution validation
  expiresAt: number;                          // Epoch-ms expiry
  elicitationSummary?: string;                // When present, confirm-action
                                              // MUST show elicitation before executing
}
```

### Expiry Handling

```typescript
const pending = store.getPendingAction(token);

if (!pending) {
  return {
    error: {
      code: "TOKEN_INVALID",
      message: "Confirmation token not found"
    }
  };
}

if (Date.now() > pending.expiresAt) {
  return {
    error: {
      code: "TOKEN_EXPIRED",
      message: "Confirmation token expired. Please re-initiate the transaction."
    }
  };
}
```

## Related Tools

| Tool | Description |
|------|-------------|
| `confirm-action` | Execute pending transaction |
| `list-pending-actions` | List all pending |
| `cancel-pending-action` | Cancel without executing |

## Best Practices

### Always Include Preview

```typescript
preview: {
  summary: "Clear description of what will happen",
  // All relevant details
  warnings: [] // Any concerns
}
```

### Handle Expiry Gracefully

```typescript
if (isExpired(token)) {
  return {
    error: {
      message: "Token expired",
      suggestion: "Re-initiate the transaction"
    }
  };
}
```

### Log Actions

```typescript
console.log(`[CONFIRM] Executing ${pending.type} from ${pending.createdAt}`);
```
