# Plugin System

Config-driven extensibility for adding new blockchains, tools, and key providers.

## Overview

Keplr Wallet MCP uses a plugin system that allows external developers to extend the server via a `keplr-mcp.config.ts` file:

- **External Plugins**: npm packages that add new chains, tools, or KeyProviders
- **Toolset Filtering**: Register only the tools needed at startup (keeps tool count manageable)
- **RPC Resolver**: Tiered endpoint selection per chain

---

## Configuration File

Create `keplr-mcp.config.ts` in your project root (or next to where the server is run):

```typescript
import { defineConfig } from "@keplr-wallet/keplr-wallet-mcp";
import osmosisPlugin from "@keplr-wallet/protocol-osmosis";

export default defineConfig({
  plugins: [
    osmosisPlugin(),
    // String form: auto-imports default export from npm package
    // "my-keplr-plugin",
  ],
  toolsets: {
    // Only register these tool categories at startup
    default: ["cosmos-query", "cosmos-transaction"],
  },
  rpc: {
    apiKey: process.env.KEPLR_RPC_API_KEY,
    overrides: {
      "cosmoshub-4": "https://my-rpc.example.com",
    },
  },
});
```

Config loading priority: `.ts` → `.js` → `.mjs` → `.json`. Returns `{}` if no config found.

### JSON format (Claude Desktop)

```json
{
  "plugins": ["@myorg/my-keplr-plugin"],
  "toolsets": { "default": ["cosmos-query", "cosmos-transaction"] },
  "rpc": { "apiKey": "${KEPLR_RPC_API_KEY}" }
}
```

## KeplrMcpPlugin Interface

Every external plugin implements this interface:

```typescript
interface KeplrMcpPlugin {
  name: string;

  // Run once before registerTools — register adapters, providers, etc.
  setup?(ctx: ExternalPluginContext): Promise<void> | void;

  // Register MCP tools, resources, prompts
  registerTools?(server: McpServer, ctx: ExternalPluginContext): Promise<void> | void;

  // Cleanup on shutdown
  teardown?(): Promise<void> | void;
}
```

Execution order: all `setup()` calls complete before any `registerTools()` begins.

### ExternalPluginContext

Shared context passed to both hooks:

```typescript
interface ExternalPluginContext {
  // Namespaced key-value store for inter-plugin data sharing
  get<T>(key: string): T | undefined;
  set(key: string, value: unknown): void;

  logger: {
    debug(msg: string): void;
    info(msg: string): void;
    warn(msg: string): void;
    error(msg: string): void;
  };
}
```

## Writing an External Plugin

### Factory Function Pattern

```typescript
// my-cosmos-plugin/src/index.ts
import type { KeplrMcpPlugin, ExternalPluginContext } from "@keplr-wallet/keplr-wallet-mcp";
import type { McpServer } from "@modelcontextprotocol/sdk/server/mcp.js";
import { z } from "zod";

export default function myPlugin(options?: { rpcUrl?: string }): KeplrMcpPlugin {
  return {
    name: "my-cosmos-plugin",

    async setup(ctx: ExternalPluginContext) {
      ctx.logger.info("Initializing my-cosmos-plugin");
      // Register adapters, providers, etc.
      ctx.set("my-cosmos-plugin.rpcUrl", options?.rpcUrl ?? "https://rpc.example.com");
    },

    async registerTools(server: McpServer, ctx: ExternalPluginContext) {
      const rpcUrl = ctx.get<string>("my-cosmos-plugin.rpcUrl");

      server.registerTool(
        "my-custom-query",
        {
          description: "Query my chain",
          inputSchema: { chainId: z.string().describe("Chain ID") },
          annotations: { readOnlyHint: true },
        },
        async ({ chainId }) => {
          // Implementation using rpcUrl
          return {
            content: [{ type: "text", text: JSON.stringify({ chainId, rpcUrl }) }],
          };
        },
      );
    },

    async teardown() {
      // Cleanup connections, timers, etc.
    },
  };
}
```

### Package Setup

```json
{
  "name": "my-keplr-plugin",
  "version": "0.1.0",
  "type": "module",
  "main": "dist/index.js",
  "peerDependencies": {
    "@keplr-wallet/keplr-wallet-mcp": "^0.1.0"
  }
}
```

### Usage in Config

```typescript
import myPlugin from "my-keplr-plugin";

export default defineConfig({
  plugins: [
    myPlugin({ rpcUrl: "https://my-rpc.example.com" }),
  ],
});
```

## Toolset Filtering

Limits which tool categories are registered at startup to keep tool count manageable (MCP clients have limits: Claude Desktop ~100, Cursor ~40).

```typescript
toolsets: {
  default: ["cosmos-query", "cosmos-transaction", "cosmwasm"],
}
```

### Available Categories

| Category | Tools |
|----------|-------|
| `cosmos-query` | get-balances, get-staking-info, list-validators, etc. |
| `cosmos-transaction` | send-tokens, delegate, vote-governance, etc. |
| `cosmwasm` | cosmwasm-query, cosmwasm-execute, etc. |
| `cosmos-signing` | cosmos-sign-arbitrary, cosmos-verify-signature |
| `account-management` | create-account, import-account, etc. |

**Always registered** (regardless of config): `meta-tools`, `accounts`, `confirm`, `auth`, `adapter-info`.

## RPC Resolver

Tiered endpoint selection per chain:

```
Priority 1: config.rpc.overrides[chainId]   (explicit per-chain URL)
Priority 2: Keplr API with apiKey           (api.keplr.app, 31 supported chains)
Priority 3: Public chain-registry RPC        (fallback, always available)
```

```typescript
rpc: {
  apiKey: process.env.KEPLR_RPC_API_KEY,    // Keplr Endpoints RPC
  overrides: {
    "cosmoshub-4": "https://my-rpc.example.com",  // Use your own node
  },
}
```

## Balance Enricher Registry

Plugin hook for enriching balance data after the standard `formatBalances → enrichIbcDenoms` pipeline. Plugins can register enrichers that resolve unresolved token metadata (symbol, decimals) using external data sources.

### BalanceEnricher Interface

```typescript
interface BalanceEnricher {
  id: string;           // Unique identifier
  chainIds: string[];   // Target chains (empty = all chains)
  enrich(balances: BalanceResult[], chainId: string): Promise<BalanceResult[]>;
}
```

### Registration

```typescript
import { balanceEnricherRegistry } from "@keplr-wallet/keplr-wallet-mcp/sdk";

// Register in plugin setup or register hook
balanceEnricherRegistry.register({
  id: "osmosis-skip",
  chainIds: ["osmosis-1"],
  enrich: async (balances, chainId) => {
    // Resolve unresolved denoms via external API
    return enrichedBalances;
  },
});
```

Enrichers run sequentially in registration order. If an enricher throws, it is skipped and the previous result is preserved.

## Internal Plugin Architecture

Internal (built-in) plugins use the `KeplrPlugin` interface, registered via `registerAll()`:

```typescript
interface KeplrPlugin {
  readonly name: string;
  readonly version?: string;
  readonly dependencies?: string[];

  register(server: McpServer, store: KeplrStore): void | Promise<void>;

  onAccountChanged?(newAccount: string | null, previousAccount: string | null): void | Promise<void>;
  onClientInitialized?(ecosystem: string, source: string): void | Promise<void>;
  onClientDisconnected?(ecosystem: string): void | Promise<void>;
  onUnload?(): void | Promise<void>;
}
```

External plugins are wrapped into this interface via `wrapExternalPlugin()` in the plugin adapter.

## Package Structure

```
packages/
  server/             # @keplr-wallet/keplr-wallet-mcp — core server
  │   src/
  │   ├── config/
  │   │   ├── types.ts          # KeplrMcpConfig, KeplrMcpPlugin, ExternalPluginContext
  │   │   ├── define-config.ts  # defineConfig() helper
  │   │   ├── loader.ts         # loadConfig() — finds keplr-mcp.config.ts
  │   │   ├── plugin-adapter.ts # wrapExternalPlugin(), resolveExternalPlugin()
  │   │   └── toolset-filter.ts # shouldRegisterPlugin()
  │   ├── utils/
  │   │   └── balance-enricher.ts  # BalanceEnricherRegistry
  │   ├── rpc/
  │   │   └── resolver.ts       # RpcResolver, getRpcResolver()
  │   └── plugins/
  │       └── index.ts          # registerAll() — wires everything together
  protocol-osmosis/   # @keplr-wallet/protocol-osmosis — Osmosis DEX plugin
```
