# State Management

Zustand-based state management for Keplr Wallet MCP.

## Overview

Keplr Wallet MCP uses Zustand for lightweight reactive state:

```typescript
import { store } from "@keplr-wallet/keplr-wallet-mcp/store";
```

## Store Structure

```typescript
interface KeplrStore {
  // Key Provider
  keyProvider: KeyProvider | null;
  setKeyProvider(provider: KeyProvider | null): void;
  getKeyProvider(): KeyProvider | null;

  // Accounts
  accounts: AccountInfo[];
  activeAccountName: string | null;
  setAccounts(accounts: AccountInfo[]): void;
  setActiveAccount(name: string): void;

  // Ecosystem Clients
  clients: Map<string, EcosystemClient>;
  getClientFor(ecosystem: EcosystemType, chainId: string): Promise<EcosystemClient>;

  // Pending Transactions
  pendingActions: Map<string, PendingAction>;
  createPendingAction(tx: CreatePendingAction): string;
  getPendingAction(token: string): PendingAction | undefined;
  executePendingAction(token: string): Promise<any>;
  removePendingAction(token: string): void;

  // Configuration
  config: KeplrConfig;
}
```

## Key Provider Management

### Setting Provider

```typescript
const provider = new MnemonicKeyProvider(mnemonic);
store.setKeyProvider(provider);
```

### Getting Provider

```typescript
const provider = store.getKeyProvider();
if (!provider) {
  throw new Error("No wallet configured");
}
```

## Client Management

### Getting Clients

```typescript
// Get client for ecosystem/chain
const cosmosClient = await store.getClientFor("cosmos", "cosmoshub-4");
```

### Client Caching

Clients are cached per ecosystem + chain:

```typescript
const key = `${ecosystem}:${chainId}`;
if (this.clients.has(key)) {
  return this.clients.get(key);
}
// Create new client...
```

## Account Management

### Account Info Structure

```typescript
interface AccountInfo {
  name: string;
  type: KeyProviderType;
  ecosystems: EcosystemType[];
  addresses: Record<string, Record<string, string>>;
  metadata?: Record<string, any>;
}
```

### Operations

```typescript
// Set accounts
store.setAccounts([
  { name: "Main", type: "mnemonic", ... }
]);

// Set active
store.setActiveAccount("Main");

// Get active
const active = store.accounts.find(a => a.name === store.activeAccountName);
```

## Pending Transactions

### Creating

```typescript
const token = store.createPendingAction({
  type: "send-tokens",
  params: { chain, to, amount },
  preview: { summary: "..." },
  execute: async () => {
    return await broadcast(tx);
  }
});
```

### Executing

```typescript
const result = await store.executePendingAction(token);
```

### Listing

```typescript
const pending = Array.from(store.pendingActions.values())
  .filter(tx => tx.expiresAt > Date.now());
```

## Zustand Usage

### Store Definition

```typescript
import { create } from "zustand";

const useStore = create<KeplrStore>((set, get) => ({
  keyProvider: null,

  setKeyProvider: (provider) => set({ keyProvider: provider }),

  getKeyProvider: () => get().keyProvider,

  // ... other methods
}));

export const store = useStore.getState();
```

### Subscribing to Changes

```typescript
// Subscribe to provider changes
useStore.subscribe(
  (state) => state.keyProvider,
  (provider) => {
    if (provider) {
      console.log("Provider set:", provider.type);
    }
  }
);
```

## Persistence

### Account Persistence

Accounts are persisted locally:

```typescript
const STORAGE_PATH = "~/.keplr-mcp/accounts.json";

async function saveAccounts(accounts: AccountInfo[]): Promise<void> {
  await fs.writeFile(STORAGE_PATH, JSON.stringify(accounts, null, 2));
}

async function loadAccounts(): Promise<AccountInfo[]> {
  const data = await fs.readFile(STORAGE_PATH, "utf-8");
  return JSON.parse(data);
}
```

### Sensitive Data

Mnemonics are encrypted at rest:

```typescript
import { encrypt, decrypt } from "./crypto.js";

// On save
const encrypted = await encrypt(mnemonic, key);

// On load
const mnemonic = await decrypt(encrypted, key);
```
