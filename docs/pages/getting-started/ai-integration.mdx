# AI Integration

Learn how to interact with Keplr Wallet MCP through AI assistants.

## Natural Language Commands

Keplr Wallet MCP is designed for conversational interactions. Instead of memorizing tool names, simply describe what you want to do.

### Example Conversations

**Checking Balances:**
```
You: "What's my ATOM balance?"
AI: Uses get-balances tool → "You have 150.5 ATOM on Cosmos Hub"

You: "Show all my tokens"
AI: Uses get-portfolio tool → Lists all balances across chains
```

**Staking:**
```
You: "I want to stake some ATOM"
AI: Uses list-validators → Shows top validators
    Uses delegate → Creates staking transaction
    Shows preview → Asks for confirmation
```

**Swapping:**
```
You: "Swap 100 OSMO for ATOM"
AI: Uses osmosis-quote → Shows exchange rate
    Uses osmosis-swap → Creates swap transaction
    Shows preview → Asks for confirmation
```

## Slash Commands (Prompts)

For guided workflows, use slash commands:

| Command | Description |
|---------|-------------|
| `/get-started` | New user onboarding |
| `/create-account` | Wallet creation guide |
| `/check-balances` | Balance checking guide |
| `/stake` | Staking walkthrough |
| `/claim-rewards` | Reward claiming guide |
| `/governance` | Governance participation |
| `/ibc-transfer` | Cross-chain transfer guide |
| `/osmosis-swap` | Osmosis swap guide |

### Using Prompts

Simply type the command in your conversation:

```
You: "/stake"
AI: "I'll help you stake your tokens. First, let me check your balances..."
    [Guided staking flow begins]
```

## Response Patterns

### Suggested Actions

Every response includes next step suggestions:

```json
{
  "balances": [...],
  "suggestedActions": [
    {
      "tool": "delegate",
      "reason": "Stake tokens to earn rewards",
      "priority": 1
    },
    {
      "tool": "send-tokens",
      "reason": "Transfer tokens",
      "priority": 2
    }
  ]
}
```

The AI uses these to proactively offer next steps:

```
AI: "Your balance is 500 ATOM. Would you like to:
    1. Stake some to earn ~15% APY
    2. Send tokens to another address
    3. Explore governance proposals"
```

### Transaction Confirmation

All state-changing operations require confirmation:

```json
{
  "status": "pending_confirmation",
  "confirmationToken": "abc123...",
  "preview": {
    "summary": "Stake 100 ATOM to Coinbase Custody",
    "from": "cosmos1...",
    "validator": "cosmosvaloper1...",
    "amount": "100 ATOM",
    "estimatedFee": "0.01 ATOM"
  }
}
```

The AI will show you a preview and ask:

```
AI: "Ready to stake 100 ATOM to Coinbase Custody.
    Fee: ~0.01 ATOM

    Should I proceed? (yes/no)"
```

### Setup Required

If you haven't set up a wallet yet:

```json
{
  "status": "setup_required",
  "message": "No wallet configured",
  "setupGuide": {
    "options": [
      {"tool": "create-account", "description": "Generate new wallet"},
      {"tool": "import-account", "description": "Import existing"}
    ]
  }
}
```

The AI will guide you through setup before proceeding.

## Best Practices

### Be Specific About Chains

Keplr supports many chains. Specify which one:

```
Good: "Show my ATOM balance on Cosmos Hub"
Good: "Send ATOM on Cosmos Hub"

Vague: "Show my balance" (AI will ask which chain)
```

### Review Before Confirming

Always review transaction previews:

```
AI: "Transaction Preview:
    Action: Send 10 ATOM
    To: cosmos1recipient...
    Fee: 0.005 ATOM

    Confirm? (yes/no)"
```

### Use Descriptive Account Names

```
You: "Create a wallet called 'Main Trading'"
You: "Create a wallet called 'Cold Storage'"
```

### Check Gas Before Large Transactions

```
You: "What's the gas cost to swap 1000 OSMO?"
AI: Uses osmosis-quote → Shows fee estimate
```

## Error Handling

### Network Errors

```json
{
  "error": {
    "category": "NETWORK",
    "message": "RPC connection failed",
    "recoverable": true,
    "suggestion": "Try again in a few moments"
  }
}
```

AI will suggest retrying or using a different RPC.

### Insufficient Funds

```json
{
  "error": {
    "category": "VALIDATION",
    "message": "Insufficient balance",
    "details": {
      "required": "100 ATOM",
      "available": "50 ATOM"
    }
  }
}
```

AI will suggest alternatives or show how to get more tokens.
