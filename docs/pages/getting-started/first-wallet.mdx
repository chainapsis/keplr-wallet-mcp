# First Wallet

Create your first wallet with Keplr Wallet MCP.

## Choose Your Wallet Type

Keplr Wallet MCP supports the following wallet types:

| Type | Security | Best For | Ecosystem Support |
|------|----------|----------|-------------------|
| **Mnemonic** | Medium | Development, testing | Cosmos |

## Option 1: Create New Mnemonic Wallet

The simplest way to get started. Ask Claude:

> "Create a new wallet for me"

Claude will use the `create-account` tool:

```json
{
  "tool": "create-account",
  "params": {
    "name": "My Wallet"
  }
}
```

**Response:**

```json
{
  "status": "success",
  "account": {
    "name": "My Wallet",
    "type": "mnemonic",
    "addresses": {
      "cosmos": "cosmos1abc...",
      "osmosis": "osmo1abc..."
    }
  },
  "mnemonic": "word1 word2 ... word24",
  "warning": "Save this mnemonic securely. It cannot be recovered."
}
```

:::warning
**Save your mnemonic phrase securely!** It's the only way to recover your wallet. Never share it with anyone.
:::

## Option 2: Import Existing Wallet

If you have an existing mnemonic phrase:

> "Import my wallet with this mnemonic: word1 word2 ..."

```json
{
  "tool": "import-account",
  "params": {
    "name": "Imported Wallet",
    "mnemonic": "word1 word2 ... word24"
  }
}
```

## Verify Your Wallet

After creating a wallet, verify it's working:

> "Show my wallet addresses"

```json
{
  "tool": "list-accounts"
}
```

**Response:**

```json
{
  "accounts": [
    {
      "name": "My Wallet",
      "type": "mnemonic",
      "active": true,
      "ecosystems": ["cosmos"]
    }
  ],
  "suggestedActions": [
    {
      "tool": "get-balances",
      "reason": "Check your token balances",
      "priority": 1
    }
  ]
}
```

## Check Balances

Once your wallet is set up:

> "Show my balances on Cosmos Hub"

```json
{
  "tool": "get-balances",
  "params": {
    "chain": "cosmoshub-4"
  }
}
```
