# Installation

Set up Keplr Wallet MCP and connect it to your AI assistant.

## Prerequisites

You need **Node.js 22 or later**. [Download here](https://nodejs.org).

To check if you already have it, open your terminal and run:

```bash
node -v
```

If you see `v22.x.x` or higher, you're good to go.

## Connect to your AI client

Pick your AI client below and follow the steps.

### Claude Code

Run this in your terminal:

```bash
claude mcp add --scope user keplr -- npx @keplr-wallet/keplr-wallet-mcp
```

If you're already in a session, type `/mcp` and connect to Keplr — or start a new session.

### Claude Desktop Configuration

**1. Find your config file:**

| OS | Path |
|----|------|
| macOS | `~/Library/Application Support/Claude/claude_desktop_config.json` |
| Windows | `%APPDATA%\Claude\claude_desktop_config.json` |

**2. Add the following to your config file:**

```json
{
  "mcpServers": {
    "keplr": {
      "command": "npx",
      "args": ["@keplr-wallet/keplr-wallet-mcp"]
    }
  }
}
```

:::tip
On Windows, use `"command": "npx.cmd"` instead of `"command": "npx"`.
:::

**3. Restart Claude Desktop** to apply changes.

### Other MCP clients

First, install the package:

:::code-group

```bash [npm]
npm install @keplr-wallet/keplr-wallet-mcp
```

```bash [pnpm]
pnpm add @keplr-wallet/keplr-wallet-mcp
```

:::

Then configure your MCP client to run the server. The command depends on your setup:

```json
{
  "mcpServers": {
    "keplr": {
      "command": "npx",
      "args": ["@keplr-wallet/keplr-wallet-mcp"]
    }
  }
}
```

## Verify installation

After setup, restart your AI client and ask:

> "What Keplr tools are available?"

If everything is working, Claude will respond with a list of wallet tools.

<details>
<summary><strong>Advanced: Global install, Plugin config</strong></summary>

### Global Install

```bash
pnpm add -g @keplr-wallet/keplr-wallet-mcp
```

Then use `"command": "keplr-wallet-mcp"` in your MCP client config.

### Plugin Configuration

To customize toolsets or RPC endpoints, create a `keplr-mcp.config.ts` in your project root:

```typescript
import { defineConfig } from "@keplr-wallet/keplr-wallet-mcp";

export default defineConfig({
  toolsets: {
    default: ["cosmos-query", "cosmos-transaction"],
  },
  rpc: {
    overrides: {
      "cosmoshub-4": "https://my-rpc.example.com",
    },
  },
});
```
