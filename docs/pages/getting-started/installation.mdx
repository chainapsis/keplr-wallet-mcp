# Installation

Install and configure Keplr Wallet MCP for your AI assistant.

## Prerequisites

- **Node.js 20+**
- **pnpm** (recommended) or npm
- **Claude Desktop** or compatible MCP client

## Installation Options

### Option 1: NPX (Recommended)

No installation required. Configure your MCP client to run directly:

```json
{
  "mcpServers": {
    "keplr": {
      "command": "npx",
      "args": ["@keplr-wallet/keplr-wallet-mcp"]
    }
  }
}
```

### Option 2: Global Install

```bash
pnpm add -g @keplr-wallet/keplr-wallet-mcp
```

Then configure:

```json
{
  "mcpServers": {
    "keplr": {
      "command": "keplr-wallet-mcp"
    }
  }
}
```

### Option 3: Local Project

```bash
pnpm add @keplr-wallet/keplr-wallet-mcp
```

```json
{
  "mcpServers": {
    "keplr": {
      "command": "node",
      "args": ["node_modules/@keplr-wallet/keplr-wallet-mcp/dist/index.js"]
    }
  }
}
```

## Claude Desktop Configuration

### macOS

Edit `~/Library/Application Support/Claude/claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "keplr": {
      "command": "npx",
      "args": ["@keplr-wallet/keplr-wallet-mcp"]
    }
  }
}
```

### Windows

Edit `%APPDATA%\Claude\claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "keplr": {
      "command": "npx.cmd",
      "args": ["@keplr-wallet/keplr-wallet-mcp"]
    }
  }
}
```

### Linux

Edit `~/.config/Claude/claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "keplr": {
      "command": "npx",
      "args": ["@keplr-wallet/keplr-wallet-mcp"]
    }
  }
}
```

## Verify Installation

After configuration, restart Claude Desktop and ask:

> "What Keplr tools are available?"

Claude should respond with a list of available wallet tools.

## Optional: DeFi Support

The base server includes Cosmos support. For Osmosis DEX integration, create a `keplr-mcp.config.ts`:

```typescript
import { defineConfig } from "@keplr-wallet/keplr-wallet-mcp";
import osmosisPlugin from "@keplr-wallet/protocol-osmosis";

export default defineConfig({
  plugins: [osmosisPlugin()],
});
```

Install the plugin:

```bash
pnpm add @keplr-wallet/protocol-osmosis
```
