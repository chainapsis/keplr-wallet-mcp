# Connect to Keplr Infra

Connect your wallet to Keplr's dedicated infrastructure for faster, more reliable chain queries.

Without an API key, Keplr Wallet MCP uses public RPC/REST endpoints. These work fine for casual use, but can be slow or unreliable during peak traffic. With a Keplr Infra API key, all requests are routed through dedicated infrastructure across 30+ Cosmos chains.

## 1. Create an Account

Go to [api.keplr.app](https://api.keplr.app) and sign up.

After signing in, you'll see a green label at the top of the dashboard showing your API key:

```
API KEY  keplr_xxxxxxxxxxxx
```

Copy this key — you'll need it in the next step.

## 2. Configure the API Key

Tell Claude:

> "Set up my Keplr Infra API key: `keplr_xxxxxxxxxxxx`"

Claude will validate the key and save it to `~/.claude.json`. This applies the key to all your projects.

:::warning
Make sure the key is saved to `~/.claude.json` (user scope). If Claude asks which scope to use, choose **user**.
:::

After the key is saved, restart your client for the key to take effect:

- **Claude Code**: Exit the current session and start a new one
- **Claude Desktop**: Quit and reopen the app

## 3. Add Credits

Keplr Infra uses credit-based billing. You can add credits in two ways:

**Option A — Ask Claude:**

> "I want to top up my Keplr Infra credits"

Claude will provide a Stripe payment link.

**Option B — From the dashboard:**

On [api.keplr.app](https://api.keplr.app), click the **Top Up** button in the top-right corner. This opens a Stripe checkout page. After payment, check that the credit count next to the Top Up button has increased.

## 4. Verify Everything Works

Ask Claude to check your usage:

> "Show my Keplr Infra API usage"

You should see your credit balance and usage stats. If the balance matches what you topped up, the key is configured correctly.

Now try a real query — for example, checking your balances:

> "Show my balances on Cosmos Hub"

Then check usage again:

> "How much API credit did I use?"

If the credit amount decreased, your requests are routing through Keplr Infra. You're all set.
