# Set Up Security

Protect your wallet with Touch ID or an authenticator app.

## How security works

Keplr Wallet MCP has two layers of protection:

1. **Transaction confirmation** (always on) — Every transaction (send, stake, swap, vote) requires you to explicitly confirm before it executes. The AI shows a preview first, and nothing happens until you say "yes." Confirmation tokens expire after 5 minutes.

2. **Authentication** (optional) — Adds Touch ID or authenticator app verification for sensitive actions. When enabled, you'll need to authenticate before:
   - **Deleting an account**
   - **Exporting your recovery phrase**

Everyday actions like checking balances, viewing proposals, or querying contracts don't require authentication — they're read-only and safe.

## Touch ID (macOS)

**1.** Tell Claude:

> "Enable biometric authentication"

**2.** Your Mac will prompt for Touch ID. Once set up, deleting accounts or exporting your mnemonic will require your fingerprint.

**3.** Verify it's working:

> "Check my auth status"

You should see biometric listed as an active provider.

## Authenticator App (Google Authenticator, etc.)

**1.** Tell Claude:

> "Set up authenticator app"

**2.** You'll see a QR code in your terminal. Scan it with your authenticator app (Google Authenticator, Authy, 1Password, or any TOTP-compatible app).

**3.** Enter the 6-digit code from your app to verify:

> "Verify TOTP with code 123456"

Once set up, protected actions will require a code from your authenticator app.

## Which should I use?

| Method | Good for |
|--------|----------|
| Touch ID | Quick and convenient — just tap your fingerprint |
| Authenticator app | Works on any machine, doesn't require Touch ID hardware |
| Both | Maximum security — two independent methods available |

## Manage authentication

**Check current status:**
```
You: "What's my auth status?"
```

**Disable a specific provider:**
```
You: "Disable my TOTP authentication"
```

**Disable authentication entirely:**
```
You: "Disable authentication"
```

You can always re-enable it later with the setup steps above.
