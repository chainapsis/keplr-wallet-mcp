# Check Balances

View your token balances across chains.

## Single chain

```
You: "Show my balance on Cosmos Hub"
You: "Show my balances on Osmosis"
```

The AI will list your tokens with amounts and denominations. If you have staked tokens, it shows those separately.

```
You: "Show my total ATOM including staked"
```

## Multiple chains

```
You: "Show my balances on Osmosis and Celestia"
You: "Show all my balances"
```

## Portfolio overview

For a full cross-chain summary with USD values:

```
You: "Show my portfolio"
```

This aggregates balances across all chains, including staked tokens and pending rewards. See [Portfolio](/guides/cosmos/portfolio) for details.

## Tips

- **IBC tokens** — Tokens transferred via IBC may show as long hash denominations (e.g., `ibc/27394...`). The AI resolves these to friendly names when possible.
- **USD prices** — Portfolio values require price data. Without a CoinGecko API key, prices use the free tier (rate-limited). See [Environment Variables](/reference/environment) to configure a key.
- **Be specific about chains** — With 50+ chains supported, specifying the chain avoids unnecessary prompting: `"Show my ATOM on Cosmos Hub"` is faster than `"Show my ATOM"`.
