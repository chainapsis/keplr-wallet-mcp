# Cosmos Overview

Introduction to the Cosmos ecosystem in Keplr Wallet MCP.

## What is Cosmos?

Cosmos is an ecosystem of interconnected blockchains:

- **Interoperability**: Chains communicate via IBC
- **Sovereignty**: Each chain has its own validators
- **Cosmos SDK**: Shared framework for building chains

## Supported Operations

| Category | Operations |
|----------|------------|
| **Query** | Balances, staking info, validators, proposals |
| **Transaction** | Send, stake, vote, IBC transfer |
| **Smart Contracts** | CosmWasm query and execute |

## Key Concepts

### Chain IDs

Each chain has a unique identifier:

| Chain | Chain ID |
|-------|----------|
| Cosmos Hub | `cosmoshub-4` |
| Osmosis | `osmosis-1` |
| Celestia | `celestia` |

### Denoms

Token denominations in Cosmos:

| Token | Denom | Unit |
|-------|-------|------|
| ATOM | `uatom` | 1 ATOM = 1,000,000 uatom |
| OSMO | `uosmo` | 1 OSMO = 1,000,000 uosmo |

### Bech32 Addresses

Cosmos uses Bech32 encoding:

```
cosmos1abc...  (Cosmos Hub)
osmo1abc...    (Osmosis)
celestia1abc... (Celestia)
```

The address changes per chain, but they're all derived from the same key.

## Common Workflows

### Check and Stake

```
1. Check balances    → get-balances
2. List validators   → list-validators
3. Stake tokens      → delegate
4. Monitor rewards   → get-staking-info
5. Claim rewards     → claim-all-rewards
```

### Cross-Chain Transfer

```
1. Check source balance  → get-balances
2. Find IBC channel      → list-ibc-channels
3. Transfer tokens       → ibc-transfer
4. Verify on destination → get-balances
```

### Governance

```
1. List proposals    → list-proposals
2. Read details      → get-proposal
3. Cast vote         → vote-governance
```

## Quick Commands

**Check your position:**
```
User: Show my ATOM balance and staking rewards
```

**Stake tokens:**
```
User: Stake 100 ATOM to the top validator on Cosmos Hub
```

**Cross-chain transfer:**
```
User: Send 50 ATOM from Cosmos Hub to Osmosis
```

**Vote on proposal:**
```
User: Vote yes on proposal 123 on Cosmos Hub
```
