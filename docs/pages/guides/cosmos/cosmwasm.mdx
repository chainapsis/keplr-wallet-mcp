# CosmWasm

Interact with smart contracts on Cosmos chains.

## How to Use

**Query a contract:**
```
You: "What's my balance on CW20 token juno1abc...?"
You: "Show info about contract juno1abc... on Juno"
```

**Execute a contract:**
```
You: "Transfer 100 tokens on CW20 juno1abc... to juno1def..."
```

You can also pass raw JSON messages:
```
You: "Query juno1abc... with {"token_info": {}}"
```

## Troubleshooting

- **"Contract not found"** — Verify the contract address and chain.
- **"Execution reverted"** — Check that you have the required permissions and correct parameters.
