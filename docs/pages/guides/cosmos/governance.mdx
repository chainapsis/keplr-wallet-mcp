# Governance

Participate in on-chain governance voting.

## Quick Commands

**View proposals:**
```
User: Show active proposals on Cosmos Hub
```

**Vote:**
```
User: Vote yes on proposal 123
```

## Understanding Governance

### How It Works

1. **Proposal submitted** with deposit
2. **Voting period** begins (typically 14 days)
3. **Token holders vote** (weighted by stake)
4. **Result determined** at end of voting
5. **Execution** if passed

### Voting Options

| Vote | Meaning |
|------|---------|
| Yes | Support the proposal |
| No | Oppose the proposal |
| Abstain | Participate but neutral |
| No With Veto | Strong opposition (can burn deposit) |

### Voting Power

Your voting power = your staked tokens.

If you don't vote, your validator's vote counts for your delegation.

```

```

## Proposal Types

### Parameter Changes

Modify chain parameters:
- Inflation rate
- Voting period
- Max validators

### Software Upgrades

Schedule chain upgrades to new versions.

### Community Pool Spend

Fund projects from community treasury.

### Text Proposals

Non-binding signaling proposals.

## Voting Strategy

### When to Vote Yes

- Proposal benefits the chain
- Well-researched and discussed
- Reasonable implementation

### When to Vote No

- Disagree with direction
- Poor implementation
- Better alternatives exist

### When to Abstain

- Unsure about implications
- Want to participate but neutral
- Technical complexity beyond understanding

### When to Vote No With Veto

- Proposal is spam
- Proposal is harmful
- Violates chain constitution

:::warning Veto Threshold
If "No With Veto" exceeds 33.4%, the proposal fails AND the deposit is burned.
:::

## Check Your Voting History

```
User: How did I vote on recent proposals?
```

## Delegator Voting

Your stake can vote even if you don't:
- Validators vote on your behalf by default
- Your explicit vote overrides validator vote
- Always vote on important proposals
