# IBC Transfer

Transfer tokens between Cosmos chains using Inter-Blockchain Communication.

## Quick Commands

**Transfer:**
```
User: Send 50 ATOM from Cosmos Hub to Osmosis
```

**Check channels:**
```
User: Show IBC channels from Cosmos Hub to Osmosis
```

## Understanding IBC

### What is IBC?

Inter-Blockchain Communication (IBC) allows:
- Token transfers between chains
- Cross-chain messages
- Interoperability without bridges

### How It Works

```
Source Chain → Relayer → Destination Chain
     ↓
  Lock/Burn tokens
     ↓
  Create proof
     ↓
  Relayer submits proof
     ↓
  Mint/Unlock tokens
```

### Transfer Time

- Typical: 30 seconds - 2 minutes
- Depends on relayer activity
- Usually very fast

## Step-by-Step Transfer

### 1. Check Source Balance

```
User: Show my ATOM on Cosmos Hub
```

### 2. Find IBC Channel (Optional)

```
User: What's the IBC channel from Cosmos Hub to Osmosis?
```

### 3. Initiate Transfer

```
User: Send 50 ATOM from Cosmos Hub to Osmosis
```

### 4. Review Preview

```json
{
  "preview": {
    "summary": "IBC transfer 50 ATOM",
    "route": {
      "source": "cosmoshub-4",
      "destination": "osmosis-1",
      "channel": "channel-0"
    },
    "from": "cosmos1sender...",
    "to": "osmo1sender...",
    "amount": "50 ATOM",
    "estimatedFee": "0.01 ATOM",
    "estimatedTime": "~30 seconds"
  }
}
```

### 5. Confirm and Wait

```
User: Yes, confirm
```

### 6. Verify on Destination

```
User: Show my balance on Osmosis
```

## IBC Token Representations

### On Source Chain

```
50 ATOM (native)
```

### On Destination Chain

```
50 ATOM (IBC)
denom: ibc/27394FB092D2EC...
```

The IBC token represents the same value but has a different denom.

### Returning Tokens

To send IBC tokens back to their origin:

```
User: Send my ATOM from Osmosis back to Cosmos Hub
```

```
User: List IBC channels from Noble to Osmosis
```

## Troubleshooting

### Transfer Taking Long

IBC usually completes in under 2 minutes. If longer:

1. Check source tx status
2. Wait for relayer (may be delayed)
3. If 10+ minutes, may need manual relay

### Tokens Not Appearing

1. Verify source transaction succeeded
2. Check correct destination chain
3. Look for IBC denom (not native denom)
4. Wait a bit longer

### "Channel not found"

1. Verify both chains are supported
2. Check for correct chain IDs
3. Some routes may not have direct channels
