# Osmosis Swap

Swap tokens on Osmosis DEX.

## How to Swap

```
You: "Swap 100 OSMO for ATOM"
You: "How much ATOM can I get for 100 OSMO?"
```

The AI will show you the exchange rate, fees, and minimum received before you confirm.

For large swaps, ask for a quote first to check the price impact:

```
You: "Quote swapping 1000 OSMO for ATOM"
```

## Slippage

You can set a custom slippage tolerance:

```
You: "Swap 100 OSMO for ATOM with 2% slippage"
```
