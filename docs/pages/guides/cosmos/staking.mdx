# Staking

Stake tokens to earn rewards.

## Stake

```
You: "Stake 100 ATOM to a good validator"
You: "Show my staking info on Cosmos Hub"
You: "Claim all my staking rewards"
```

The AI will suggest validators and show you the expected APY before you confirm.

## Unstake

```
You: "Unstake 50 ATOM from Validator A"
```

## Cancel Unstake

```
You: "Cancel my unbonding from Validator A"
```

## Redelegate

```
You: "Move 100 ATOM from Validator A to Validator B"
```

## Compound Rewards

Claim and re-stake in one go:

```
You: "Claim my rewards and stake them to Validator A"
```
