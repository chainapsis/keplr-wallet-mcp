# Staking

Stake tokens to earn rewards and secure the network.

## Quick Commands

**Stake tokens:**
```
User: Stake 100 ATOM to a good validator
```

**Check staking:**
```
User: Show my staking info on Cosmos Hub
```

**Claim rewards:**
```
User: Claim all my staking rewards
```

## Understanding Staking

### What is Staking?

- **Delegate** tokens to validators
- **Earn rewards** (~10-20% APY typically)
- **Secure** the network through proof-of-stake
- **Keep custody** of your tokens (not transferred to validator)

### Key Terms

| Term | Meaning |
|------|---------|
| Delegation | Tokens staked with a validator |
| Rewards | Earnings from staking |
| Unbonding | Process of unstaking (has waiting period) |
| Commission | Validator's fee (deducted from rewards) |

## Complete Staking Flow

### 1. Check Available Balance

```
User: How much ATOM do I have available to stake?
```

### 2. Research Validators

```
User: Show me the best validators on Cosmos Hub
```

Consider:
- **Commission**: Lower = more rewards for you
- **Uptime**: Higher = more reliable
- **Voting power**: Spread across validators for decentralization
- **Self-stake**: Higher = validator has skin in game

### 3. Delegate Tokens

```
User: Stake 100 ATOM to Validator A
```

## Unstaking

### Start Unbonding

```
User: Unstake 50 ATOM from Validator A
```

:::warning Unbonding Period
Unstaking takes time (21 days on Cosmos Hub). During this period:
- Tokens don't earn rewards
- Tokens can't be transferred
- You can cancel unbonding
:::

### Check Unbonding Status

```
User: Show my unbonding delegations
```

### Cancel Unbonding

```
User: Cancel my unbonding from Validator A
```

## Redelegation

Move stake between validators without unbonding:

```
User: Move 100 ATOM from Validator A to Validator B
```

Benefits:
- No unbonding period
- Continuous rewards
- Immediate effect

Limitation:
- Can't redelegate the same tokens again for 21 days

## Choosing Validators

### Recommended Criteria

| Factor | Guideline |
|--------|-----------|
| Commission | 5-10% is reasonable |
| Uptime | 99%+ preferred |
| Self-stake | Shows commitment |
| Governance | Active participation |
| Community | Good reputation |

### Diversification

Spread across multiple validators:
- Reduces slashing risk
- Supports decentralization
- Different commission rates

```
User: Stake 50 ATOM each to 3 different validators
```
