# Osmosis Swap

Swap tokens on Osmosis DEX.

## Quick Commands

**Get quote:**
```
User: How much ATOM can I get for 100 OSMO?
```

**Execute swap:**
```
User: Swap 100 OSMO for ATOM
```

## Step-by-Step

### 1. Check Balance

```
User: Show my balance on Osmosis
```

### 2. Get Quote

```
User: Quote swapping 100 OSMO for ATOM
```

Response:

```json
{
  "quote": {
    "tokenIn": "100 OSMO",
    "tokenOut": "~8.5 ATOM",
    "exchangeRate": "1 OSMO = 0.085 ATOM",
    "priceImpact": "0.12%"
  },
  "fees": {
    "swapFee": "0.2%",
    "networkFee": "~0.01 OSMO"
  },
  "minimumReceived": "8.415 ATOM"
}
```

### 3. Execute Swap

```
User: Swap 100 OSMO for ATOM with 1% slippage
```

### 4. Review Preview

```json
{
  "preview": {
    "summary": "Swap 100 OSMO for ~8.5 ATOM",
    "tokenIn": "100 OSMO",
    "tokenOut": "~8.5 ATOM",
    "minimumReceived": "8.415 ATOM",
    "fees": {
      "swap": "0.2 OSMO",
      "network": "0.01 OSMO"
    }
  }
}
```

### 5. Confirm

```
User: Yes, confirm
```

### 6. Verify Result

```
User: Show my balance on Osmosis
```

|--------|----------|--------|
| < $100 | 1% | Default |
| $100-$1000 | 0.5-1% | Normal |

| Volatile token | 2-3% | Price moves |

```
STARS → ATOM
├─ STARS → OSMO (Pool #604)

```

Automatically handled - you just specify tokens.

## Troubleshooting

### "Slippage exceeded"

Price moved more than your tolerance.

**Solution:**
1. Increase slippage
2. Try smaller amount
3. Wait for less volatile period

### "Insufficient liquidity"

Pool can't handle your trade size.

**Solution:**
1. Split into smaller trades
2. Try different route
3. Wait for liquidity
