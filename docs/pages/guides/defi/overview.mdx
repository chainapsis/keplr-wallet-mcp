## Key Concepts

### Slippage

The difference between expected and actual price:

| Setting | Use Case |
|---------|----------|
| 0.5% | Stable pairs, high liquidity |
| 1% | Most swaps (default) |
| 3% | Volatile pairs |
| 5%+ | Very volatile or low liquidity |

### Price Impact

How your trade affects the pool price:

| Impact | Meaning |
|--------|---------|
| < 0.1% | Negligible |
| 0.1-1% | Normal |
| 1-5% | Significant |
| > 5% | Consider smaller trade |

### Minimum Received

Worst-case amount you'll receive:

```
Expected: 8.5 ATOM
Slippage: 1%
Minimum: 8.415 ATOM
```

If price moves beyond slippage, transaction fails (protecting you).

## Choosing Between DEXes

### Osmosis (Cosmos)

- **Best for**: Cosmos tokens (ATOM, OSMO, TIA)
- **Fees**: ~0.2-0.3%
- **Speed**: Fast (~6 seconds)
- **Liquidity**: Deep for Cosmos assets
