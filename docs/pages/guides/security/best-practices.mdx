# Security Best Practices

Protect your assets when using Keplr Wallet MCP.

## Account Security

### Choose the Right Account Type

| Value at Risk | Recommended |
|---------------|-------------|
| Testing only | Mnemonic |
| < $1,000 | Mnemonic + Auth |
| > $1,000 | Mnemonic + Auth + Biometric |

### Mnemonic Security

**Do:**
- Write on paper or metal
- Store in secure location
- Use dedicated wallet for AI interactions
- Enable biometric authentication

**Don't:**
- Screenshot or photograph
- Store in cloud notes
- Share with anyone
- Use primary holdings wallet

## Transaction Security

### Always Review Previews

Before confirming, verify:

- [ ] Recipient address correct
- [ ] Amount correct
- [ ] Chain correct
- [ ] Fees reasonable
- [ ] No unexpected warnings

### Double-Check Large Transactions

For high-value transactions:

1. Verify recipient outside of chat
2. Start with small test transaction
3. Wait for confirmation before full amount

### Use Address Book / Names

When possible, use:
- ENS names (`vitalik.eth`)
- Previously verified addresses

## Authentication

### Enable Biometric Auth

```
User: Set up biometric authentication
```

Adds hardware-level protection.

### Session Timeouts

Balance security and convenience:

| Risk Level | Session Timeout |
|------------|-----------------|
| High value | Disabled |
| Normal | 5-15 minutes |
| Development | 30 minutes |

### Regular Session Clearing

```
User: Clear my auth session
```

After sensitive operations or when stepping away.

## Operational Security

### Separate Accounts

Use different accounts for:
- Day-to-day transactions
- Long-term holdings
- DeFi activities
- NFT/gaming

### Monitor Activity

Regularly check:
- Recent transactions
- Staking positions
### Keep Software Updated

- Update Keplr Wallet MCP
- Update Claude Desktop
- Update mobile wallet apps
- Update operating system

## Red Flags

### Be Suspicious Of

| Prompt | Risk |
|--------|------|
| "Send to this address for free tokens" | Scam |
| "Share your mnemonic to verify" | Theft |
| "Urgent action required" | Social engineering |
| "Connect wallet to claim airdrop" | Phishing |

### Transaction Warnings

Pay attention to warnings in previews:

- "Large amount" - Double-check
- "Unknown recipient" - Verify address
- "High gas" - Network congested
- "First transaction to address" - Extra verification

## Recovery Planning

### Mnemonic Accounts

1. Secure seed phrase backup
2. Test recovery on new device
3. Document derivation paths

## Incident Response

### If Compromised

1. **Don't panic**
2. Move remaining assets immediately
3. Revoke permissions/sessions
4. Create new accounts
5. Report if applicable

### If Mnemonic Exposed

1. Create new wallet immediately
2. Transfer all assets to new wallet
3. Never use compromised mnemonic again
