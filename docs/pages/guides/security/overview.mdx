# Security Overview

Security features and best practices for Keplr Wallet MCP.

## Security Layers

| Layer | Protection | Tools |
|-------|------------|-------|
| Key Storage | Encrypted local storage | Mnemonic |
| Authentication | Biometric verification | Touch ID, Face ID |
| Transaction | Preview + Confirmation | Confirmation Flow |
| Session | Time-limited auth sessions | Session Auth |

## Account Security by Type

### Mnemonic Accounts

| Aspect | Status |
|--------|--------|
| Key storage | Encrypted locally |
| Key backup | 24-word seed phrase |
| Transaction auth | Optional biometric |
| Recovery | Seed phrase only |

**Risks:**
- Seed phrase exposure
- No hardware protection
- Social engineering

## Security Features

### Biometric Authentication

Require Touch ID/Face ID for transactions:

```
User: Set up biometric authentication
```

### Session Authentication

Reduce auth prompts within time window:

```
User: Enable session auth with 15 minute timeout
```

### Transaction Confirmation

Two-step process for all state changes:

```
1. Preview (amounts, fees, warnings)
2. Explicit confirmation
```

### TTL for Confirmations

Confirmation tokens expire (default 5 minutes):

```
// Environment variable
KEPLR_TX_TTL_MINUTES=5
```

## Security Checklist

### Initial Setup

- [ ] Choose appropriate account type
- [ ] Secure mnemonic backup (if applicable)
- [ ] Enable biometric authentication
- [ ] Set reasonable session timeout
- [ ] Verify addresses before funding

### Ongoing

- [ ] Review transactions before confirming
- [ ] Monitor for unusual activity
- [ ] Keep software updated
- [ ] Use separate accounts for different purposes

### Advanced

- [ ] Enable multiple auth factors
- [ ] Regular security audits
- [ ] Limit AI tool permissions
