# Import Wallet

Import an existing wallet using a mnemonic phrase.

## When to Import

- Moving from another wallet app
- Restoring a backed-up wallet
- Using same wallet across devices

## Quick Start

```
User: Import my wallet with mnemonic: word1 word2 ... word24
```

## Step-by-Step

### 1. Prepare Your Mnemonic

Have your 12 or 24-word mnemonic phrase ready:
- Check the word count (12 or 24)
- Verify spelling of each word
- Ensure correct order

### 2. Import the Wallet

```
User: Import this wallet: abandon abandon abandon abandon abandon abandon abandon abandon abandon abandon abandon about
```

Or with a custom name:

```
User: Import wallet named "Recovered" with mnemonic: word1 word2 ...
```

### 3. Verify Import

```json
{
  "status": "success",
  "account": {
    "name": "Recovered",
    "type": "mnemonic",
    "addresses": {
      "cosmos": "cosmos1abc...",
      "osmosis": "osmo1abc...",
      "ethereum": "0x123..."
    }
  }
}
```

### 4. Check Balances

```
User: Show my balances on Cosmos Hub
```

Your existing balances should appear.

## Security Warnings

:::danger Mnemonic Exposure
When you type your mnemonic into a conversation:
- It may be logged
- It passes through the AI system
- It's stored locally by the MCP server

For maximum security, only import mnemonics you're comfortable exposing to these systems.
:::

### Safe Import Practices

1. **Use in trusted environment** - Private computer, secure network
2. **Consider dedicated wallets** - Import wallets specifically for AI interaction
3. **Small amounts first** - Test with minimal funds
4. **Enable authentication** - Add biometric protection after import

## Supported Mnemonic Formats

| Format | Words | Entropy |
|--------|-------|---------|
| Standard | 12 | 128-bit |
| Extended | 24 | 256-bit |

Both BIP39-compliant formats are supported.

## Common Issues

### "Invalid mnemonic"

**Causes:**
- Incorrect word spelling
- Wrong word order
- Missing or extra words
- Non-BIP39 words

**Solutions:**
1. Double-check each word against [BIP39 word list](https://github.com/bitcoin/bips/blob/master/bip-0039/english.txt)
2. Verify word count (exactly 12 or 24)
3. Check for typos in similar words

### Wrong addresses

**Cause:** Different derivation path than expected.

Keplr Wallet MCP uses standard derivation paths:
- Cosmos: `m/44'/118'/0'/0/0`
- Ethereum: `m/44'/60'/0'/0/0`

If your previous wallet used different paths, addresses will differ.

### Missing balances

**Causes:**
- Imported to wrong account
- Checking wrong chain
- Network sync issue

**Solutions:**
1. Verify imported addresses match expected
2. Check correct chain ID
3. Wait and retry

## Migration from Other Wallets

### From Keplr Extension

1. Export mnemonic from Keplr Extension settings
2. Import using that mnemonic
3. Addresses will match exactly

## After Import

1. **Verify addresses** - Compare with original wallet
2. **Check balances** - Ensure assets are visible
3. **Set up authentication** - Enable biometric protection
4. **Test small transaction** - Verify signing works
