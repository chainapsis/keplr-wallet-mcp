## What is Keplr Wallet MCP?

Keplr Wallet MCP brings your Cosmos wallet into AI assistants like Claude. Describe what you want in everyday language, and the AI executes it for you.

- **50+ Cosmos chains**: Cosmos Hub, Osmosis, Celestia, and more
- **Token swaps**: Osmosis DEX

### Natural Language Wallet Operations

Ask your AI assistant things like:
- "Show my ATOM balance on Cosmos Hub"
- "Stake 100 ATOM to a top validator"
- "Swap 50 OSMO to ATOM on Osmosis"

### Wallet Security

Your wallet is protected by a **24-word recovery phrase** (mnemonic). The recovery phrase is encrypted and stored in your OS credential store (e.g. macOS Keychain).

## Quick Start

**1. Install Node.js** — [Download here](https://nodejs.org) (v22 or later). If you're not sure whether you have it, open Terminal (Mac) or Command Prompt (Windows) and type `node -v`.

**2. Connect to your AI client** — Pick your client and follow the steps:

<details>
<summary><strong>Claude Code</strong></summary>

Run this in your terminal:

```bash
claude mcp add --scope user keplr -- npx @keplr-wallet/keplr-wallet-mcp
```

If you're already in a session, type `/mcp` and connect to Keplr — or start a new session.

</details>

<details>
<summary><strong>Claude Desktop</strong></summary>

Add this to your config file ([how to find this file](/getting-started/installation#claude-desktop-configuration)):

```json
{
  "mcpServers": {
    "keplr": {
      "command": "npx",
      "args": ["@keplr-wallet/keplr-wallet-mcp"]
    }
  }
}
```

No separate installation needed — `npx` downloads and runs it automatically.

</details>

<details>
<summary><strong>Other MCP clients</strong></summary>

First, install the package:

:::code-group

```bash [npm]
npm install @keplr-wallet/keplr-wallet-mcp
```

```bash [pnpm]
pnpm add @keplr-wallet/keplr-wallet-mcp
```

:::

Then configure your MCP client to run the installed package. See [Installation](/getting-started/installation) for detailed options.

</details>

**3. Start chatting** — Ask Claude: **"Help me set up a wallet"**
