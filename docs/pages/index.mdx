# Keplr Wallet MCP

AI-powered wallet interface for Cosmos chains via Model Context Protocol (MCP).

## What is Keplr Wallet MCP?

Keplr Wallet MCP is a **Model Context Protocol** server that allows AI assistants like Claude to interact with blockchain wallets. It supports:

- **Cosmos Ecosystem**: Cosmos Hub, Osmosis, Celestia, and 50+ chains
- **DeFi Protocols**: Osmosis DEX

## Key Features

### Multi-Chain Support

```
Cosmos: cosmoshub-4, osmosis-1, celestia, neutron-1, ...
```

### Natural Language Wallet Operations

Ask your AI assistant things like:
- "Show my ATOM balance on Cosmos Hub"
- "Stake 100 ATOM to a top validator"
- "Swap 50 OSMO to ATOM on Osmosis"

### Wallet Type

| Type | Best For | Security |
|------|----------|----------|
| **Mnemonic** | Development, testing | Local storage |

## Quick Start

:::code-group

```bash [npm]
npm install @keplr-wallet/keplr-wallet-mcp
```

```bash [pnpm]
pnpm add @keplr-wallet/keplr-wallet-mcp
```

:::

Configure Claude Desktop (`claude_desktop_config.json`):

```json
{
  "mcpServers": {
    "keplr": {
      "command": "npx",
      "args": ["@keplr-wallet/keplr-wallet-mcp"]
    }
  }
}
```

Then ask Claude: **"Help me set up a wallet"**
