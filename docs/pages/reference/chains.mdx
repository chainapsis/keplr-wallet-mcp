### Keplr Infrastructure

When `KEPLR_RPC_API_KEY` is configured, the following chains use Keplr's dedicated RPC/REST endpoints (`api.keplr.app`) instead of public fallbacks. Unsupported chains automatically fall back to public chain-registry endpoints. See [Environment Variables](/reference/environment#keplr_rpc_api_key) for setup.
