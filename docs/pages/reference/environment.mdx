# Environment Variables

Configuration options for Keplr Wallet MCP.

## Quick Reference

| Variable | Description | Required |
|----------|-------------|----------|
| `KEPLR_MNEMONIC` | Wallet recovery phrase (env-based import) | No |
| `KEPLR_RPC_API_KEY` | Keplr infrastructure RPC/LCD API key | No |
| `COINGECKO_API_KEY` | CoinGecko Pro API key for portfolio prices | No |
| `KEPLR_TX_TTL_MINUTES` | Transaction confirmation TTL | No |
| `SKIP_API_URL` | Skip API base URL (default: `https://api.skip.build`) | No |
| `SKIP_API_KEY` | Skip API key for IBC routing and Osmosis swaps | No |

Plugin configuration (plugins, toolsets, RPC overrides) is done via the config file, not environment variables.


## Wallet Configuration

### `KEPLR_MNEMONIC`

If you want to avoid exposing your mnemonic in the AI conversation window and chat history, you can set it directly as an environment variable. When set, the server automatically registers it as an `env` account on startup.

```json
{
  "env": {
    "KEPLR_MNEMONIC": "word1 word2 word3 ... word24"
  }
}
```

- Supports 12/15/18/21/24 word mnemonics.
- The mnemonic is never saved to the keychain — it is read from the environment variable each time.
- No need to use the `import-account` tool in the conversation.


### `KEPLR_TX_TTL_MINUTES`

Transaction confirmation token time-to-live.

```json
{
  "env": {
    "KEPLR_TX_TTL_MINUTES": "5"
  }
}
```

Default: `5` minutes


## Price Data

### `COINGECKO_API_KEY`

CoinGecko Pro API key for USD price data in `get-portfolio`. Without this key, the free tier is used with automatic rate limit protection.

```json
{
  "env": {
    "COINGECKO_API_KEY": "CG-xxxxxxxxxxxxxxxxxxxx"
  }
}
```

Get an API key from [CoinGecko API](https://www.coingecko.com/en/api).

| Behavior | Without Key (Free) | With Key (Pro) |
|----------|-------------------|----------------|
| API endpoint | `api.coingecko.com` | `pro-api.coingecko.com` |
| Cache TTL | 5 minutes | 60 seconds |
| Request throttle | 2s between requests | None |
| Retry on rate limit | 3 retries with exponential backoff | 1 retry |


## RPC Configuration

### `KEPLR_RPC_API_KEY`

Keplr infrastructure API key. When set, uses Keplr's dedicated RPC endpoints for [supported chains](/reference/chains#keplr-infrastructure) instead of public fallbacks.

Create an API key from the [Keplr API Dashboard](https://api.keplr.app), then add it to your config:

```json
{
  "env": {
    "KEPLR_RPC_API_KEY": "keplr_xxxxxxxxxxxxxxxxxxxx"
  }
}
```

Per-chain overrides and plugin configuration are done in the config file.


## Skip API

### `SKIP_API_URL`

Base URL for the Skip API, used for IBC routing and Osmosis swap routes.

```json
{
  "env": {
    "SKIP_API_URL": "https://api.skip.build"
  }
}
```

Default: `https://api.skip.build`

### `SKIP_API_KEY`

Skip API key for authenticated access. When set, requests include an `authorization` header. Without a key, the public API is used with no authentication.

```json
{
  "env": {
    "SKIP_API_KEY": "your-skip-api-key"
  }
}
```

The Skip API client is a simple fetch wrapper with a 15-second timeout. There is no built-in retry logic, throttle, or cooldown.

## Full Configuration Example

### Claude Desktop (macOS)

`~/Library/Application Support/Claude/claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "keplr": {
      "command": "npx",
      "args": ["@keplr-wallet/keplr-wallet-mcp"],
      "env": {
        "COINGECKO_API_KEY": "CG-xxxxxxxxxxxxxxxxxxxx",
        "KEPLR_TX_TTL_MINUTES": "10"
      }
    }
  }
}
```

### Development Environment

`.env` file (if using dotenv):

```bash
# Price Data (optional)
COINGECKO_API_KEY=CG-xxxxxxxxxxxxxxxxxxxx

KEPLR_TX_TTL_MINUTES=30
```


## Environment Variable Priority

1. **Explicit env in config**: Highest priority
2. **System environment**: Falls back if not in config
3. **Defaults**: Used if not set anywhere


## Verifying Configuration

After setting environment variables, verify with Claude:

```

```
