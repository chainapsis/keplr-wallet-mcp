# Error Codes

Reference for all error categories and handling.

## Error Categories

| Category | Pattern | Recoverable | Description |
|----------|---------|-------------|-------------|
| `TIMEOUT` | timeout, timed out, deadline exceeded | Yes | Operation timeout |
| `NETWORK` | network, econnrefused, fetch failed | Yes | Network/RPC issues |
| `VALIDATION` | insufficient, invalid address, slippage, contract not found, invalid ABI | Varies | Input validation (slippage errors are recoverable) |
| `WALLET` | user rejected, cancelled, signing failed | Yes | Wallet/signing issues |
| `SETUP_REQUIRED` | no mnemonic, no account | Yes | Onboarding needed |
| `AUTH` | *(no matching patterns in classifyError)* | N/A | Authentication issues (category exists but has no patterns in the error classification system) |
| `CHAIN` | gas, rpc error, sequence mismatch, revert, nonce, LCD parse error | Varies | Blockchain errors |
| `UNKNOWN` | unrecognized | No | Unexpected errors |

> **Note:** The `AUTH` category is defined in `ErrorCategory` enum but has no matching patterns in the `classifyError` function. Auth-related errors will be classified as `UNKNOWN` unless explicitly constructed.


## TIMEOUT Errors

### Operation Timeout

```json
{
  "category": "timeout",
  "message": "The operation timed out",
  "recoverable": true,
  "suggestion": "The operation timed out. Check your network connection and try again."
}
```

**Patterns:** `timeout`, `timed out`, `deadline exceeded`

### Token Expired

```json
{
  "category": "timeout",
  "message": "Confirmation token expired",
  "recoverable": true,
  "suggestion": "The confirmation token expired. Please request the transaction again."
}
```

**Patterns:** `expired token`, `token expired`, `invalid token`, `confirmation expired`

## SETUP_REQUIRED Errors

### Onboarding Required

The `createSetupRequiredResponse` function returns a non-error guide:

```json
{
  "status": "setup_required",
  "message": "No wallet is configured yet. Choose one of the options below to get started.",
  "attemptedAction": "get-balances",
  "setupGuide": {
    "options": [
      {
        "tool": "create-account",
        "description": "Generate a new wallet with a fresh mnemonic phrase",
        "recommendedFor": "New users who don't have an existing wallet"
      },
      {
        "tool": "import-account",
        "description": "Import an existing wallet using your mnemonic phrase",
        "recommendedFor": "Users who already have a wallet they want to use"
      }
    ],
    "recommendation": "create-account",
    "tip": "For best security, enable biometric authentication with 'auth-setup' after creating your account."
  }
}
```

When classified as an error via `classifyError`:

```json
{
  "category": "setup_required",
  "message": "No mnemonic configured. Use create-account or import-account.",
  "recoverable": true,
  "suggestion": "No wallet is configured yet. Create a new account or import an existing wallet to get started."
}
```

**Patterns:** `no mnemonic configured`, `no active account`, `account not found`, `mnemonic not stored`, `use create-account`, `use import-account`

## Transaction Warnings

Warnings included in transaction previews. These are non-blocking — transactions can still proceed.

| Code | Level | Trigger |
|------|-------|---------|
| `INSUFFICIENT_FOR_FEE` | critical | Balance < amount + estimated fee |
| `LARGE_AMOUNT` | warning | Amount > 90% of balance |
| `LOW_BALANCE_AFTER` | warning | Remaining balance < 10% after transaction |
| `UNSTAKING_PERIOD` | info | Undelegate operation (21-day unbonding) |
| `GAS_TOKEN_EXHAUSTION` | warning/critical | Remaining gas token balance < 3x estimated fee after transfer |
| `DENOM_NOT_IN_BALANCES` | warning | Requested denom not found in on-chain balances |

### GAS_TOKEN_EXHAUSTION

Triggered when a `send-tokens` or `ibc-transfer` would leave insufficient gas tokens for future transactions.

```json
{
  "preview": {
    "warnings": [{
      "level": "warning",
      "code": "GAS_TOKEN_EXHAUSTION",
      "message": "After this transaction, remaining 0.005 ATOM may not cover fees for future transactions (estimated 0.015 ATOM needed for ~3 transactions)."
    }]
  },
  "suggestedActions": [
    {
      "tool": "send-tokens",
      "reason": "Reduce amount to 0.98 ATOM to reserve gas for future transactions",
      "params": { "amount": "980000", "denom": "uatom" },
      "priority": 1
    }
  ]
}
```

**Level escalation:**
- `warning` — remaining balance is positive but below the reserve threshold
- `critical` — remaining balance would be zero or negative (subsequent transactions will fail)


## ClassifiedError Interface

The `classifyError` function returns a `ClassifiedError` object:

```typescript
interface ClassifiedError {
  category: ErrorCategory;   // "network" | "validation" | "wallet" | "timeout" | "auth" | "chain" | "setup_required" | "unknown"
  message: string;           // Original error message
  recoverable: boolean;      // Whether the operation can be retried
  suggestion?: string;       // How to resolve the error
  retryAction?: RetryAction; // Added by enhanceWithRetryAction()
  setupGuide?: SetupGuide;   // Added for SETUP_REQUIRED errors
}
```

## Error Handling in Code

```typescript
import { classifyError, isSetupRequiredError, createSetupRequiredResponse } from "@keplr-wallet/keplr-wallet-mcp/errors";

try {
  // Operation
} catch (error) {
  if (isSetupRequiredError(error.message)) {
    return createSetupRequiredResponse({ attemptedAction: "tool-name" });
  }

  const classified = classifyError(error);
  return {
    error: {
      category: classified.category,
      message: classified.message,
      recoverable: classified.recoverable,
      suggestion: classified.suggestion
    }
  };
}
```
