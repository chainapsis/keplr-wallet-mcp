# Glossary

Blockchain and MCP terminology reference.

## A

### AMM (Automated Market Maker)
DEX mechanism using liquidity pools instead of order books. Examples: Osmosis.

### APR/APY
Annual Percentage Rate/Yield. The expected yearly return from staking or liquidity provision.

## B

### Bech32
Address encoding format used by Cosmos chains. Example: `cosmos1abc...`

### BIP39
Standard for mnemonic seed phrases (12 or 24 words).

## C

### Chain ID
Unique identifier for a blockchain network. Examples: `cosmoshub-4`, `osmosis-1`, `juno-1`.

### Confirmation Flow
Two-step transaction pattern: preview → confirm. Prevents accidental transactions.

### CosmWasm
Smart contract framework for Cosmos chains. Uses Rust/WebAssembly.

### CW721
Cosmos NFT standard, similar to ERC-721 on Ethereum.

## D

### Delegation
Staking tokens with a validator to earn rewards.

### Denom
Token identifier in Cosmos. Example: `uatom` (micro-ATOM, 1 ATOM = 1,000,000 uatom).

### DER
Distinguished Encoding Rules. Binary format for cryptographic signatures.

## E

### EOA (Externally Owned Account)
Traditional wallet controlled by a private key.

## F

### Feegrant
Cosmos feature allowing one account to pay fees for another.

## G

### Gas
Computational cost unit for blockchain transactions.

### Governance
On-chain voting system for protocol changes. Proposals, voting, execution.

## I

### IBC (Inter-Blockchain Communication)
Cosmos protocol for cross-chain token transfers and communication.

## K

### KeyProvider
Keplr abstraction for key management. Implementations: Mnemonic.

## L

### Low-S
Signature normalization required by some protocols. Ensures S value is in lower half of curve order.

## M

### MCP (Model Context Protocol)
Protocol enabling AI assistants to interact with external tools and services.

### Mnemonic
Seed phrase (12 or 24 words) used to derive wallet keys.

## N

### Nonce
Transaction counter preventing replay attacks.

## R

### Redelegate
Move staked tokens between validators without unbonding period.

### RPC
Remote Procedure Call. API endpoint for blockchain interaction.

## S

### secp256k1
Elliptic curve used by Bitcoin, Ethereum, and Cosmos for standard wallets.

### Signer
Keplr abstraction for cryptographic signing. Implementation: Secp256k1.

### Slippage
Price difference between expected and executed trade. Set tolerance to prevent bad trades.

### Staking
Locking tokens to secure the network and earn rewards.

## T

### Transaction Preview
Pre-execution view of transaction details (amount, fee, recipient).

### TTL (Time To Live)
Expiration time for confirmation tokens.

## U

### Unbonding
Process of unstaking tokens. Usually has a waiting period (e.g., 21 days).

## V

### Validator
Node operator who participates in consensus and validates transactions.

## Z

### Zustand
State management library used by Keplr Wallet MCP.
