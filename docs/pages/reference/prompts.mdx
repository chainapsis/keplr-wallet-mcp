# Prompts Reference

Guided workflows accessible via slash commands.

## Overview

Prompts provide step-by-step guidance for common operations. Use them by typing the command in your conversation with Claude.

## Onboarding & Setup

| Prompt | Description |
|--------|-------------|
| `/get-started` | New user onboarding guide |
| `/create-account` | Create a new wallet |
| `/import-account` | Import existing mnemonic |
| `/setup-authentication` | Configure biometric auth |
| `/security-check` | Security audit and recommendations |

### `/get-started`

Complete onboarding flow for new users:

1. Explains wallet types
2. Helps choose the right type
3. Guides through creation
4. Sets up authentication
5. Shows first operations

### `/create-account`

Guided wallet creation:

1. Generates secure mnemonic
2. Shows important security warnings
3. Provides address for all chains
4. Suggests next steps (check balance, stake)

### `/setup-authentication`

Biometric authentication setup:

1. Checks available auth methods
2. Configures Touch ID/Face ID
3. Sets session timeout
4. Tests authentication

### `/security-check`

Security audit:

1. Checks authentication status
2. Reviews account settings
3. Identifies potential risks
4. Provides recommendations

## Using Prompts

### Basic Usage

Simply type the prompt in your conversation:

```
User: /stake
AI: I'll help you stake your tokens...
    [Guided flow begins]
```

### With Context

Prompts work with existing conversation context:

```
User: I have 500 ATOM on Cosmos Hub
User: /stake
AI: I see you have 500 ATOM. Let me show you the best validators...
```

### Prompt Parameters

Some prompts accept additional parameters:

```
User: /stake cosmoshub-4
AI: [Starts staking flow for Cosmos Hub specifically]
```

## Prompt vs Direct Commands

| Approach | When to Use |
|----------|-------------|
| Prompts | Learning, complex flows, step-by-step guidance |
| Direct | Experienced users, specific operations |

**Prompt approach:**
```
User: /stake
AI: [Multi-step guided flow with explanations]
```

**Direct approach:**
```
User: Stake 100 ATOM to Coinbase Custody
AI: [Creates transaction immediately]
```

Both approaches are valid - prompts provide more guidance, direct commands are faster.
