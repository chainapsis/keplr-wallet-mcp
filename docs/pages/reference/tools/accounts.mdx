# Account Management Tools

Tools for creating, managing, and switching between wallet accounts.

## Overview

| Tool | Description | Read-Only |
|------|-------------|-----------|
| `onboarding-status` | Check wallet setup progress | Yes |
| `create-account` | Generate new wallet with mnemonic | No |
| `import-account` | Import existing mnemonic | No |
| `list-accounts` | List all accounts | Yes |
| `switch-account` | Change active account | No |
| `rename-account` | Rename an account | No |
| `delete-account` | Remove an account | No |
| `export-mnemonic` | Export recovery phrase | No |
| `get-account-addresses` | Get all chain addresses | Yes |
| `list-pending-actions` | List pending confirmations | Yes |
| `cancel-pending-action` | Cancel pending transaction | No |
| `check-vault-health` | Check vault integrity and repair anomalies | No |
| `get-portfolio` | Get all balances across chains | Yes |

## `create-account`

Generate a new wallet with a BIP39 mnemonic phrase.

### Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | Unique name for the account (e.g., 'trading', 'savings') |
| `strength` | `"12" \| "24"` | No | Number of mnemonic words: 12 or 24 (default: "24") |
| `description` | `string` | No | Optional description for the account |
| `setActive` | `boolean` | No | Whether to set this as the active account (default: true) |

### Response

```json
{
  "status": "success",
  "account": {
    "name": "My Wallet",
    "type": "mnemonic",
    "addresses": {
      "cosmos": "cosmos1..."
    }
  },
  "mnemonic": "word1 word2 ... word24",
  "warning": "Save this mnemonic securely"
}
```

:::warning
The mnemonic is only shown once. Store it securely offline.
:::

### Example

```
Request: { "name": "Trading Wallet" }
Response: {
  "status": "success",
  "account": {
    "name": "Trading Wallet",
    "type": "mnemonic"
  },
  "mnemonic": "abandon abandon ... about",
  "suggestedActions": [
    { "tool": "get-balances", "reason": "Check your balances", "priority": 1 }
  ]
}
```


## `import-account`

Import an existing wallet using a mnemonic phrase. Includes security confirmation.

### Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | Unique account name |
| `mnemonic` | `string` | No | BIP39 mnemonic (12/15/18/21/24 words). If omitted and client supports elicitation, mnemonic will be collected securely via a password form. |
| `description` | `string` | No | Optional description |
| `setActive` | `boolean` | No | Set as active account (default: true) |

### Security Confirmation

Before import, the tool prompts for confirmation via elicitation:

```
⚠️ Security Warning - Mnemonic Import

You are about to import a mnemonic phrase. Please understand:
• Your mnemonic phrase is visible in this AI conversation

Do you want to proceed?
```

If declined, the response includes alternatives:

```json
{
  "status": "cancelled",
  "alternatives": [
    { "tool": "import-account", "description": "Import existing mnemonic" }
  ]
}
```

### Response

```json
{
  "status": "success",
  "account": {
    "name": "Imported Wallet",
    "type": "mnemonic",
    "wordCount": 24
  },
  "addresses": { "Cosmos": "cosmos1..." },
  "security": {
    "storage": "OS Keychain (secure)",
    "warnings": [
      "🚨 Your mnemonic was visible in this conversation"
    ],
    "recommendation": "Enable biometric auth with 'auth-setup'"
  },
  "nextSteps": [
    { "step": 1, "action": "Set up biometric security", "priority": "high" },
    { "step": 2, "action": "Check your balances" }
  ]
}
```

:::warning
Your mnemonic phrase is visible in AI conversation history.
:::

## `export-mnemonic`

Export the mnemonic (recovery phrase) for an account. Requires confirmation and authentication when auth is enabled.

### Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | No | Account name (defaults to active account) |
| `totpCode` | `string` | No | 6-digit TOTP code from authenticator app. Required when TOTP authentication is enabled. |

### Response

```json
{
  "success": true,
  "mnemonic": "word1 word2 ... word24",
  "accountName": "My Wallet",
  "wordCount": 24,
  "securityWarnings": [
    "This mnemonic gives full access to all derived accounts and assets.",
    "Never share it digitally — store it offline in a secure location.",
    "If compromised, immediately transfer all assets to a new wallet.",
    "Consider deleting this conversation after noting the mnemonic."
  ]
}
```

### Security Considerations

:::warning
The mnemonic (recovery phrase) provides **full, irrevocable access** to all accounts
and assets derived from it. Unlike passwords, a compromised mnemonic cannot be changed.
:::

- This tool requires authentication when auth is enabled
- The mnemonic is returned in the tool response — avoid storing conversation logs containing it
- If you suspect the mnemonic has been exposed, transfer all assets to a new wallet immediately
- Only mnemonic-based accounts support export — passkey accounts will return an error

## `get-portfolio`

| `includeStaking` | `boolean` | No | Include staking delegations and rewards for Cosmos chains (default: true) |
| `includePrices` | `boolean` | No | Include USD price data from CoinGecko (default: true) |

### Price Data

Prices are fetched from CoinGecko with automatic tier handling:

| Tier | Cache TTL | Throttle | Retries | Trigger |
|------|-----------|----------|---------|---------|
| **Free** (default) | 5 minutes | 2s between requests | 3 retries with backoff | No `COINGECKO_API_KEY` |
| **Pro** | 60 seconds | None | 1 retry | `COINGECKO_API_KEY` set |

When rate-limited, the response includes a `priceNote` with recovery guidance and a suggested action to retry without prices.

See [Environment Variables](/reference/environment#coingecko_api_key) for API key configuration.

### Features

- **Cosmos coverage**: Queries all configured Cosmos chains in parallel
- **Graceful degradation**: Skips unavailable chains without error
- **Staking summary**: Aggregates delegations and unclaimed rewards
- **Rate limit protection**: Exponential backoff retry on CoinGecko 429 responses
