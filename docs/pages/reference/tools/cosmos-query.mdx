# Cosmos Query Tools

Read-only tools for querying Cosmos blockchain state.

## Overview

| Tool | Description |
|------|-------------|
| `list-cosmos-chains` | List supported Cosmos chains |
| `get-cosmos-address` | Get address for specific chain |
| `get-balances` | Get token balances |
| `get-staking-info` | Get staking delegations and rewards |
| `list-validators` | List validators |
| `get-unbonding` | Get unbonding delegations |
| `list-proposals` | List governance proposals |
| `get-proposal` | Get proposal details |
| `list-fee-tokens` | List fee token options |
| `get-transaction-status` | Check transaction status |
| `list-ibc-channels` | List IBC channels |
| `list-transaction-history` | Get transaction history |

---

## `list-cosmos-chains`

List all supported Cosmos chains.

### Parameters

None required.

### Response

```json
{
  "chains": [
    {
      "chainId": "cosmoshub-4",
      "chainName": "Cosmos Hub",
      "nativeToken": "ATOM",
      "bech32Prefix": "cosmos"
    },
    {
      "chainId": "osmosis-1",
      "chainName": "Osmosis",
      "nativeToken": "OSMO",
      "bech32Prefix": "osmo"
    }
  ]
}
```

## `list-validators`

List validators with commission and voting power.

### Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `chain` | `string` | Yes | Chain ID or name |
| `status` | `string` | No | Filter: "active", "inactive", "jailed", "all" (default: "active") |
| `limit` | `number` | No | Max results, 1-100 (default: 20) |

### Response

```json
{
  "validators": [
    {
      "operatorAddress": "cosmosvaloper1...",
      "name": "Coinbase Custody",
      "commission": "0.10",
      "votingPower": "5.2%",
      "jailed": false,
      "uptime": "99.9%"
    }
  ],
  "suggestedActions": [
    { "tool": "delegate", "reason": "Stake to a validator", "priority": 1 }
  ]
}
```

## `list-ibc-channels`

List IBC channels to other chains.

### Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `chain` | `string` | Yes | Source chain ID or name |
| `counterpartyChain` | `string` | No | Filter by counterparty chain ID (e.g., 'cosmoshub-4') |
| `state` | `string` | No | Filter by channel state: "OPEN", "CLOSED", "all" (default: "OPEN") |
| `limit` | `number` | No | Max number of channels to return (default: 50) |
| `offset` | `number` | No | Number of channels to skip for pagination (default: 0) |

### Response

```json
{
  "channels": [
    {
      "channelId": "channel-0",
      "portId": "transfer",
      "counterparty": {
        "chainId": "osmosis-1",
        "channelId": "channel-141"
      },
      "state": "open"
    }
  ],
  "suggestedActions": [
    { "tool": "ibc-transfer", "reason": "Transfer tokens via IBC", "priority": 1 }
  ]
}
```
