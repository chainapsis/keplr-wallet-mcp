# Cosmos Query Tools

Read-only tools for querying Cosmos blockchain state.

## Overview

| Tool | Description |
|------|-------------|
| `list-cosmos-chains` | List supported Cosmos chains |
| `get-cosmos-address` | Get address for specific chain |
| `get-balances` | Get token balances |
| `get-staking-info` | Get staking delegations and rewards |
| `list-validators` | List validators |
| `get-unbonding` | Get unbonding delegations |
| `list-proposals` | List governance proposals |
| `get-proposal` | Get proposal details |
| `list-fee-tokens` | List fee token options |
| `get-transaction-status` | Check transaction status |
| `list-ibc-channels` | List IBC channels |
| `list-transaction-history` | Get transaction history (confirm plugin) |

## `get-transaction-status`

Check the status of a submitted transaction.

### Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `txHash` | `string` | Yes | Transaction hash |
| `chain` | `string` | Yes | Chain ID or name (e.g., 'cosmoshub-4' or 'cosmos') |

### Response

```json
{
  "chainId": "cosmoshub-4",
  "hash": "ABC123...",
  "status": "confirmed",
  "height": 12345678,
  "code": 0,
  "gasUsed": "80000",
  "gasWanted": "100000",
  "rawLog": "...",
  "timestamp": "2024-01-01T00:00:00Z",
  "suggestedActions": [
    { "tool": "get-balances", "reason": "Check your updated balance after the transaction", "params": { "chain": "cosmoshub-4" }, "priority": 1 }
  ]
}
```

Status values: `"confirmed"` (code=0), `"failed"` (code!=0), or `"not_found"`.


## `list-ibc-channels`

List IBC channels to other chains.

### Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `chain` | `string` | Yes | Source chain ID or name |
| `counterpartyChain` | `string` | No | Filter by counterparty chain ID (e.g., 'cosmoshub-4') |
| `state` | `string` | No | Filter by channel state: "OPEN", "CLOSED", "all" (default: "OPEN") |
| `limit` | `number` | No | Max number of channels to return (default: 50) |
| `offset` | `number` | No | Number of channels to skip for pagination (default: 0) |

### Response

```json
{
  "chainId": "osmosis-1",
  "chainName": "Osmosis",
  "totalChannels": 120,
  "returnedChannels": 50,
  "hasMore": true,
  "pagination": { "offset": 0, "limit": 50 },
  "filter": { "state": "OPEN", "counterpartyChain": null },
  "channels": [
    {
      "channelId": "channel-0",
      "portId": "transfer",
      "state": "OPEN",
      "counterpartyChannelId": "channel-141",
      "counterpartyPortId": "transfer",
      "connectionId": "connection-0",
      "ordering": "UNORDERED",
      "counterpartyChainId": "cosmoshub-4"
    }
  ],
  "suggestedActions": [
    { "tool": "ibc-transfer", "reason": "Transfer tokens via channel-0 to cosmoshub-4", "params": { "chain": "osmosis-1", "sourceChannel": "channel-0" }, "priority": 1 },
    { "tool": "get-balances", "reason": "Check available tokens before transferring", "params": { "chain": "osmosis-1" }, "priority": 2 }
  ],
  "tip": "Use the channelId (e.g., 'channel-0') as the sourceChannel parameter in ibc-transfer."
}
```


## `list-transaction-history`

Get transaction history. This tool is part of the confirm plugin, not the query plugin. It returns transactions that were executed through the confirmation flow.

### Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `chain` | `string` | No | Filter by chain ID (e.g., 'osmosis-1', 'cosmoshub-4') |
| `limit` | `number` | No | Maximum number of transactions to return (default: 20) |

### Response

```json
{
  "message": "Found 2 transaction(s)",
  "count": 2,
  "transactions": [
    {
      "id": "abc-123",
      "summary": "Delegate 100 ATOM to Coinbase Custody",
      "status": "success",
      "chain": "cosmoshub-4",
      "txHash": "DEF456...",
      "timestamp": "2024-01-10T12:00:00Z",
      "timeAgo": "2 hours ago"
    }
  ],
  "suggestedActions": [
    { "tool": "get-transaction-status", "reason": "Check status of most recent transaction", "params": { "chain": "cosmoshub-4", "txHash": "DEF456..." }, "priority": 1 }
  ]
}
```
