# Cosmos Transaction Tools

Tools for executing transactions on Cosmos chains. All transactions require confirmation.

## Overview

| Tool | Description |
|------|-------------|
| `send-tokens` | Send tokens to another address |
| `ibc-transfer` | Cross-chain IBC transfer |
| `delegate` | Stake tokens to a validator |
| `undelegate` | Unstake tokens (unbonding period) |
| `redelegate` | Move stake between validators |
| `claim-rewards` | Claim rewards from one validator |
| `claim-all-rewards` | Claim all staking rewards |
| `vote-governance` | Vote on governance proposal |
| `cancel-unbonding` | Cancel unbonding delegation |


## Confirmation Flow

All transaction tools use a two-step confirmation flow:

**Step 1: Preview**
```json
{
  "status": "pending_confirmation",
  "summary": "Send 100 ATOM to cosmos1... on cosmoshub-4",
  "chain": "cosmoshub-4",
  "preview": {
    "from": "cosmos1sender...",
    "to": "cosmos1recipient...",
    "amount": { "value": "100000000", "denom": "uatom", "formatted": "100 ATOM" },
    "estimatedFee": { "value": "5000", "denom": "uatom", "formatted": "0.005 ATOM" },
    "feeEstimationMethod": "simulated",
    "balanceBefore": { "value": "500000000", "denom": "uatom", "formatted": "500 ATOM" },
    "balanceAfter": { "value": "399995000", "denom": "uatom", "formatted": "399.995 ATOM" },
    "summary": "Send 100 ATOM to cosmos1... on cosmoshub-4"
  },
  "confirmationToken": "abc123...",
  "expiresIn": "5 minutes",
  "expiresAt": "2026-03-31T12:05:00.000Z",
  "ttlWarning": "This confirmation token will expire in 5 minutes.",
  "instruction": "Call confirm-action with this token to execute."
}
```

**Step 2: Confirm**
```json
{
  "tool": "confirm-action",
  "params": {
    "confirmationToken": "abc123..."
  }
}
```


## `send-tokens`

Send tokens to another address on the same chain.

### Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `chain` | `string` | Yes | Chain ID or name |
| `recipientAddress` | `string` | Yes | Bech32 recipient address |
| `amount` | `string` | Yes | Amount (e.g., "1 ATOM", "1.5", or "1000000") |
| `denom` | `string` | No | Token denomination (optional, auto-detected from amount) |
| `feeDenom` | `string` | No | Fee token denomination (auto-selects if not specified) |

### Response (Preview)

```json
{
  "status": "pending_confirmation",
  "summary": "Send 100 ATOM to cosmos1recipient... on cosmoshub-4",
  "chain": "cosmoshub-4",
  "preview": {
    "from": "cosmos1sender...",
    "to": "cosmos1recipient...",
    "amount": { "value": "100000000", "denom": "uatom", "formatted": "100 ATOM" },
    "estimatedFee": { "value": "5000", "denom": "uatom", "formatted": "0.005 ATOM" },
    "feeEstimationMethod": "simulated",
    "balanceBefore": { "value": "500000000", "denom": "uatom", "formatted": "500 ATOM" },
    "balanceAfter": { "value": "399995000", "denom": "uatom", "formatted": "399.995 ATOM" },
    "summary": "Send 100 ATOM to cosmos1recipient... on cosmoshub-4"
  },
  "confirmationToken": "abc123...",
  "expiresIn": "5 minutes",
  "expiresAt": "2026-03-31T12:05:00.000Z",
  "ttlWarning": "This confirmation token will expire in 5 minutes.",

```json

## `ibc-transfer`

Transfer tokens across chains via IBC. Source channel is automatically resolved via Skip API if omitted.

### Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `chain` | `string` | Yes | Source chain ID or name |
| `recipientAddress` | `string` | Yes | Recipient address on destination (bech32) |
| `amount` | `string` | Yes | Amount to transfer (e.g., '10 ATOM', '10000000') |
| `denom` | `string` | Yes | Token denomination to transfer |
| `destChain` | `string` | No | Destination chain ID or name. Required when the recipient address prefix is ambiguous (e.g., 'terra' matches both Terra and Terra Classic). |
| `sourceChannel` | `string` | No | IBC source channel (e.g., 'channel-0'). Auto-resolved via Skip API if omitted. |
| `sourcePort` | `enum: "transfer"` | No | IBC source port (must be 'transfer') |
| `timeoutMinutes` | `number` | No | Timeout in minutes (default: 10) |
| `feeDenom` | `string` | No | Fee token denomination |

### Response (Preview)

```json
{
  "status": "pending_confirmation",
  "summary": "IBC transfer 100 ATOM to osmo1recipient... via transfer/channel-0 on cosmoshub-4",

## `cancel-unbonding`

Cancel an unbonding delegation and re-stake tokens.

### Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `chain` | `string` | Yes | Chain ID or name |
| `validatorAddress` | `string` | Yes | Validator operator address (e.g., 'cosmosvaloper1...') |
| `amount` | `string` | Yes | Amount to cancel unbonding (e.g., '10 ATOM', '10.5', or '10000000') |
| `creationHeight` | `string` | Yes | Creation height of the unbonding entry (from get-unbonding output) |
| `denom` | `string` | No | Token denomination (optional, defaults to stake denom) |
| `feeDenom` | `string` | No | Fee token denomination |


## Error Handling

### Common Errors

| Error | Category | Recoverable | Description |
|-------|----------|-------------|-------------|
| `insufficient funds` | validation | No | Not enough balance for amount + fees |
| `account sequence mismatch` | chain | Yes | Retry after pending tx confirms |
| `timeout` | timeout | Yes | Network congestion, retry |
| `gas estimation failed` | chain | Yes | Increase gas limit and retry |
| `invalid address` | validation | No | Check address format |

### Error Response with Retry Action

For recoverable errors (network, timeout, chain), the response includes a `retryAction`:

```json
{
  "isError": true,
  "category": "chain",
  "message": "account sequence mismatch, expected 42, got 41",
  "recoverable": true,
  "suggestion": "Chain RPC error occurred. Wait a moment and try again.",
  "retryAction": {
    "tool": "send-tokens",
    "params": {
      "chain": "cosmoshub-4",
      "recipientAddress": "cosmos1...",
      "amount": "100",
      "denom": "uatom"
    },
    "autoRetry": true
  },
  "suggestedActions": [
    { "tool": "get-balances", "reason": "Check your token balances", "priority": 1 }
  ]
}
```

### Non-Recoverable Error Response

For validation errors:

```json
{
  "isError": true,
  "category": "validation",
  "message": "Insufficient balance for this transaction",
  "recoverable": false,
  "suggestion": "Insufficient balance. Please add funds to your wallet and try again.",
  "suggestedActions": [
    { "tool": "get-balances", "reason": "Check your token balances", "priority": 1 }
  ]
}
