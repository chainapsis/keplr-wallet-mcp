# CosmWasm Tools

Tools for interacting with CosmWasm smart contracts.

## Overview

| Tool | Description | Read-Only |
|------|-------------|-----------|
| `cosmwasm-query` | Query contract state | Yes |
| `cosmwasm-contract-info` | Get contract metadata | Yes |
| `cosmwasm-list-contracts` | List contracts by code ID | Yes |
| `cosmwasm-execute` | Execute contract function | No |
| `cosmwasm-instantiate` | Deploy new contract instance | No |

## Supported Chains

CosmWasm is supported on:

- Osmosis (`osmosis-1`)
- Stargaze (`stargaze-1`)
- Injective (`injective-1`)
- Terra Classic (`columbus-5`)


## `cosmwasm-query`

Query contract state (read-only).

### Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `chain` | `string` | Yes | Chain ID or name |
| `contractAddress` | `string` | Yes | Contract address (bech32 format) |
| `queryMsg` | `string` | Yes | Query message as JSON string |

### Response

```json
{
  "chainId": "osmosis-1",
  "contractAddress": "osmo1token...",
  "query": { "balance": { "address": "osmo1user..." } },
  "result": { ... },
  "suggestedActions": [
    { "tool": "cosmwasm-contract-info", "reason": "View contract metadata", "params": { "chain": "osmosis-1", "contractAddress": "osmo1token..." }, "priority": 1 },
    { "tool": "cosmwasm-execute", "reason": "Execute a contract action", "params": { "chain": "osmosis-1", "contractAddress": "osmo1token..." }, "priority": 2 }
  ]
}
```

### Example: Query CW20 Token Balance

```json
Request: {
  "chain": "osmosis-1",
  "contractAddress": "osmo1token...",
  "queryMsg": "{\"balance\":{\"address\":\"osmo1user...\"}}"
}

Response: {
  "chainId": "osmosis-1",
  "contractAddress": "osmo1token...",
  "query": { "balance": { "address": "osmo1user..." } },
  "result": {
    "balance": "1000000"
  },
  "suggestedActions": [...]
}
```

### Example: Query CW721 Owner

```json
Request: {
  "chain": "stargaze-1",
  "contractAddress": "stars1nft...",
  "queryMsg": "{\"owner_of\":{\"token_id\":\"123\"}}"
}

Response: {
  "chainId": "stargaze-1",
  "contractAddress": "stars1nft...",
  "query": { "owner_of": { "token_id": "123" } },
  "result": {
    "owner": "stars1...",
    "approvals": []
  },
  "suggestedActions": [...]
}
```


## `cosmwasm-contract-info`

Get contract metadata including code ID, admin, and label.

### Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `chain` | `string` | Yes | Chain ID or name |
| `contractAddress` | `string` | Yes | Contract address (bech32 format) |

### Response

```json
{
  "chainId": "osmosis-1",
  "contract": {
    "address": "osmo1...",
    "codeId": "123",
    "creator": "osmo1...",
    "admin": "osmo1...",
    "label": "My Token Contract",
    "ibcPortId": null
  },
  "suggestedActions": [
    { "tool": "cosmwasm-query", "reason": "Query the contract state", "params": { "chain": "osmosis-1", "contractAddress": "osmo1..." }, "priority": 1 },
    { "tool": "cosmwasm-execute", "reason": "Execute a contract action", "params": { "chain": "osmosis-1", "contractAddress": "osmo1..." }, "priority": 2 }
  ]
}
```


## `cosmwasm-list-contracts`

List CosmWasm contract addresses by code ID. Use this to discover contracts deployed from a specific code.

### Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `chain` | `string` | Yes | Chain ID or name (e.g., 'osmosis-1', 'stargaze-1', 'injective-1') |
| `codeId` | `string` | Yes | Code ID to search contracts for (numeric, e.g., '1', '100') |

### Response

```json
{
  "chainId": "osmosis-1",
  "codeId": "100",
  "totalContracts": 5,
  "contracts": [
    "osmo1contract1...",
    "osmo1contract2..."
  ],
  "suggestedActions": [
    { "tool": "cosmwasm-contract-info", "reason": "View metadata for a discovered contract", "priority": 1 }
  ]
}
```


## `cosmwasm-execute`

Execute a contract function (requires confirmation).

### Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `chain` | `string` | Yes | Chain ID or name |
| `contractAddress` | `string` | Yes | Contract address (bech32 format) |
| `executeMsg` | `string` | Yes | Execute message as JSON string |
| `funds` | `string` | No | Optional funds as JSON array string |
| `feeDenom` | `string` | No | Fee token denomination (optional) |

### Response (Preview)

```json
{
  "status": "pending_confirmation",
  "confirmationToken": "...",
  "preview": {
    "action": "Execute CosmWasm Contract",
    "chain": "osmosis-1",
    "chainName": "Osmosis",
    "contract": "osmo1token...",
    "message": "transfer",
    "messageDetails": { "transfer": { "recipient": "osmo1recipient...", "amount": "1000000" } },
    "funds": [],
    "sender": "osmo1sender..."
  },
  "instructions": "To execute this contract action, call the confirm-action tool with confirmationToken: \"...\"",
  "warnings": [
    "Contract executions may transfer tokens or change state",
    "Verify the contract address and message carefully"
  ]
}
```

### Example: CW20 Transfer

```json
Request: {
  "chain": "osmosis-1",
  "contractAddress": "osmo1token...",
  "executeMsg": "{\"transfer\":{\"recipient\":\"osmo1recipient...\",\"amount\":\"1000000\"}}"
}
```

### Example: CW20 Send (with contract interaction)

```json
Request: {
  "chain": "osmosis-1",
  "contractAddress": "osmo1token...",
  "executeMsg": "{\"send\":{\"contract\":\"osmo1staking...\",\"amount\":\"1000000\",\"msg\":\"eyJzdGFrZSI6e319\"}}"
}
```

### Example: Execute with Funds

```json
Request: {
  "chain": "osmosis-1",
  "contractAddress": "osmo1swap...",
  "executeMsg": "{\"swap\":{\"offer_asset\":{\"native\":{\"denom\":\"uosmo\"}},\"ask_asset\":{\"native\":{\"denom\":\"uatom\"}}}}",
  "funds": "[{\"denom\":\"uosmo\",\"amount\":\"1000000\"}]"
}
```


## `cosmwasm-instantiate`

Deploy a new instance of an uploaded contract.

### Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `chain` | `string` | Yes | Chain ID or name |
| `codeId` | `string` | Yes | Code ID to instantiate (e.g., '1', '123') |
| `instantiateMsg` | `string` | Yes | Instantiate message as JSON string (format depends on the contract) |
| `label` | `string` | Yes | Human-readable label for the contract |
| `admin` | `string` | No | Admin address for contract migrations (leave empty for immutable) |
| `funds` | `string` | No | Optional funds as JSON array string |
| `feeDenom` | `string` | No | Fee token denomination (optional) |

### Response (Preview)

```json
{
  "status": "pending_confirmation",
  "confirmationToken": "...",
  "preview": {
    "action": "Instantiate CosmWasm Contract",
    "chain": "osmosis-1",
    "chainName": "Osmosis",
    "codeId": "123",
    "label": "My New Token",
    "admin": "osmo1...",
    "instantiateMsg": { "name": "My Token", "symbol": "MYT", "decimals": 6 },
    "funds": [],
    "sender": "osmo1sender..."
  },
  "instructions": "To instantiate this contract, call the confirm-action tool with confirmationToken: \"...\"",
  "warnings": [
    "Contract instantiation creates a new contract instance",
    "This contract will have an admin and can be migrated"
  ]
}
```

### Response (After Confirmation)

```json
{
  "transactionHash": "ABC123...",
  "code": 0,
  "gasUsed": "250000",
  "gasWanted": "400000",
  "events": [...],
  "contractAddress": "osmo1newcontract...",
  "suggestedActions": [
    { "tool": "get-transaction-status", "reason": "Check transaction confirmation status", "params": { "chain": "osmosis-1", "txHash": "ABC123..." }, "priority": 1 },
    { "tool": "get-balances", "reason": "Check updated token balances", "params": { "chain": "osmosis-1" }, "priority": 2 },
    { "tool": "get-staking-info", "reason": "Check updated staking positions and rewards", "params": { "chain": "osmosis-1" }, "priority": 3 }
  ]
}
```

### Example: Instantiate CW20 Token

```json
Request: {
  "chain": "osmosis-1",
  "codeId": "1",
  "instantiateMsg": "{\"name\":\"My Token\",\"symbol\":\"MYT\",\"decimals\":6,\"initial_balances\":[{\"address\":\"osmo1...\",\"amount\":\"1000000000000\"}],\"mint\":{\"minter\":\"osmo1...\"}}",
  "label": "My Token Contract",
  "admin": "osmo1..."
}
```


## Common Query Patterns

### CW20 Token Standard

```json
// Balance
{ "balance": { "address": "..." } }

// Token Info
{ "token_info": {} }

// All Accounts (paginated)
{ "all_accounts": { "limit": 100 } }
```

### CW721 NFT Standard

```json
// Owner of Token
{ "owner_of": { "token_id": "123" } }

// NFT Info
{ "nft_info": { "token_id": "123" } }

// All NFT Info
{ "all_nft_info": { "token_id": "123" } }

// Tokens by Owner
{ "tokens": { "owner": "...", "limit": 100 } }

// Contract Info
{ "contract_info": {} }
```

### CW4 Group

```json
// Member Info
{ "member": { "addr": "..." } }

// List Members
{ "list_members": { "limit": 100 } }
```
