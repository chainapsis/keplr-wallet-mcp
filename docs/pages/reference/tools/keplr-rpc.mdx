# Keplr Infra API Tools

Tools for managing Keplr Infra API keys, credits, and usage analytics via `api.keplr.app`.

## Overview

| Tool | Description | Read-Only |
|------|-------------|-----------|
| `keplr_api_configure_key` | Configure API key (auto-detects Claude Code, Desktop, or other clients) | No |
| `keplr_api_validate_key` | Validate an API key | Yes |
| `keplr_api_get_payment_link` | Get Stripe payment link to add credits | Yes |
| `keplr_api_get_usage_summary` | Get balance and usage summary with per-chain breakdown | Yes |
| `keplr_api_get_usage_history` | Get usage history with filters | Yes |
| `keplr_api_get_credit_history` | Get credit transaction history (top-ups, adjustments) | Yes |
| `keplr_api_list_chains` | List available chains (no auth) | Yes |

## About Keplr Infra API

Keplr Infra provides dedicated RPC and REST endpoints for Cosmos chains:

- **Reliable infrastructure**: Dedicated endpoints instead of public fallbacks
- **API key auth**: All requests authenticated via `X-API-Key` header
- **Credit-based billing**: Pay-as-you-go with credit balance tracking
- **31 supported chains**: See [Keplr Infrastructure](/reference/chains#keplr-infrastructure)
- **Dashboard**: [api.keplr.app](https://api.keplr.app)


## `keplr_api_configure_key`

Configure a Keplr Infra API key. Validates the key, then saves it to the MCP configuration file based on the detected client. Restart required after configuration.

### Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `apiKey` | `string` | Yes | Keplr Infra API key (starts with `keplr_`) |
| `scope` | `"user" \| "project"` | No | Claude Code only: `user` for `~/.claude.json` (all projects), `project` for `.mcp.json` (this project only). Defaults to `user`. Ignored for other clients. |

### Response

**Claude Code:**

```json
{
  "status": "configured",
  "message": "API key saved to ~/.claude.json (user scope).",
  "configPath": "/Users/you/.claude.json",
  "scope": "user",
  "restartRequired": true,
  "restartGuide": "The API key will take effect after restarting the MCP server...",
  "suggestedActions": [
    { "tool": "keplr_api_get_usage_summary", "reason": "Check your credit balance and usage", "priority": 1 },
    { "tool": "keplr_api_list_chains", "reason": "See which chains are available", "priority": 2 }
  ]
}
```

**Claude Desktop:**

```json
{
  "status": "configured",
  "message": "API key saved to Claude Desktop config.",
  "configPath": "/Users/you/Library/Application Support/Claude/claude_desktop_config.json",
  "restartRequired": true,
  "restartGuide": "Quit and reopen Claude Desktop to apply the new API key.",
  "suggestedActions": [...]
}
```

**Other clients:** Returns `unsupported_client` status. Only Claude Code and Claude Desktop are supported.

## `keplr_api_validate_key`

Validate an existing Keplr Infra API key.

### Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `apiKey` | `string` | Yes | API key to validate |

### Response

```json
{
  "valid": true,
  "userId": "user-1",
  "suggestedActions": [
    { "tool": "keplr_api_get_usage_summary", "reason": "Check credits and usage", "priority": 1 },
    { "tool": "keplr_api_list_chains", "reason": "See available chains", "priority": 2 }
  ]
}
```


## `keplr_api_get_payment_link`

Get a Stripe payment link to add credits.

### Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `apiKey` | `string` | Yes | API key |

### Response

```json
{
  "paymentUrl": "https://checkout.stripe.com/...",
  "suggestedActions": [
    { "tool": "keplr_api_get_credit_history", "reason": "Verify exact credit top-up amount after payment", "priority": 1 },
    { "tool": "keplr_api_get_usage_summary", "reason": "Check current balance and usage overview", "priority": 2 }
  ]
}
```


## `keplr_api_get_usage_summary`

Get balance and usage summary including requests, credits, and per-chain breakdown.

### Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `apiKey` | `string` | Yes | API key |

### Response

```json
{
  "balance": 2000000,
  "usage": {
    "last7Days": { "totalRequests": 500, "totalCredits": 500 },
    "byChain": [
      { "chain": "cosmoshub-4", "totalRequests": 300, "totalCredits": 300 },
      { "chain": "osmosis-1", "totalRequests": 200, "totalCredits": 200 }
    ]
  },
  "suggestedActions": [
    { "tool": "keplr_api_get_usage_history", "reason": "View detailed usage over time", "priority": 2 }
  ]
}
```

When balance is low, a `keplr_api_get_payment_link` suggestion is added at priority 1.


## `keplr_api_get_usage_history`

Get usage history with optional date, chain, and endpoint type filters.

### Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `apiKey` | `string` | Yes | API key |
| `startDate` | `string` | No | Start date (ISO format) |
| `endDate` | `string` | No | End date (ISO format) |
| `chain` | `string` | No | Filter by chain ID |
| `endpointType` | `string` | No | Filter by endpoint type |

### Response

```json
{
  "history": [
    { "date": "2025-01-01", "requests": 100, "credits": 10 },
    { "date": "2025-01-02", "requests": 200, "credits": 20 }
  ],
  "suggestedActions": [
    { "tool": "keplr_api_get_usage_summary", "reason": "View aggregated usage summary", "priority": 1 }
  ]
}
```


## `keplr_api_get_credit_history`

Get credit transaction history including top-ups and adjustments. Use after payment to verify the exact recharge amount.

### Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `apiKey` | `string` | Yes | API key |

### Response

```json
{
  "history": {
    "entries": [
      {
        "id": "2",
        "type": "topup",
        "amount": 10000000,
        "balanceAfter": 10999500,
        "description": "Stripe payment: 10.00 USD",
        "createdAt": "2025-03-05T14:30:00.000Z"
      }
    ]
  },
  "suggestedActions": [
    { "tool": "keplr_api_get_usage_summary", "reason": "View current balance and usage overview", "priority": 1 }
  ]
}
```

## `keplr_api_list_chains`

List all chains available on Keplr Infra. No authentication required.

### Parameters

None.

### Response

```json
{
  "chains": [
    { "chainId": "cosmoshub-4", "chainName": "Cosmos Hub" },
    { "chainId": "osmosis-1", "chainName": "Osmosis" }
  ]
}
```


## Error Handling

| HTTP Status | Behavior |
|-------------|----------|
| 402 | Credit error with `keplr_api_get_payment_link` suggestion |
| 403 | Setup guide with dashboard link (not treated as error) |
| 404 | Resource not found |
| 429 | Rate limit exceeded |
| 5xx | Server error |


## Example Workflows

### First-Time Setup

```
1. keplr_api_list_chains
   → Browse available chains (no auth needed)

2. keplr_api_validate_key
   → Validate your API key

3. keplr_api_get_usage_summary
   → Check credit balance and usage
```

### Monitor Usage

```
1. keplr_api_get_usage_summary
   → Overview of requests and credits per chain

2. keplr_api_get_usage_history
   → Drill into specific date ranges or chains

3. keplr_api_get_payment_link
   → Add credits if balance is low

4. keplr_api_get_credit_history
   → Verify exact top-up amount after payment
```
