# Account API

Interface for wallet account abstraction.

## Import

```typescript
import { Account, AccountKind, EOAAccount } from "@keplr-wallet/keplr-wallet-mcp/keys";
```

## Interface

```typescript
interface Account {
  readonly kind: AccountKind;
  getSigners(): Signer[];
  getAddress(ecosystem: EcosystemType, chainId: string): Promise<string>;
}
```

## Types

```typescript
type AccountKind = "eoa";
```

## Properties

### `kind`

```typescript
readonly kind: AccountKind;
```

The type of account.

| Kind | Description |
|------|-------------|
| `eoa` | Externally Owned Account (private key controlled) |

## Methods

### `getSigners`

```typescript
getSigners(): Signer[];
```

Get the signers associated with this account.

**Returns:** Array of `Signer` instances

**Note:** Returns an array with one signer for standard EOA accounts.

### `getAddress`

```typescript
getAddress(ecosystem: EcosystemType, chainId: string): Promise<string>;
```

Get the address for a specific ecosystem and chain.

**Parameters:**
- `ecosystem` - Target ecosystem (`"cosmos"`)
- `chainId` - Chain identifier

**Returns:** Address string

**Example:**

```typescript
const cosmosAddr = await account.getAddress("cosmos", "cosmoshub-4");
// "cosmos1abc..."
```

## Usage with Adapters

Adapters interact with accounts through KeyProviders:

```typescript
class MyAdapter implements EcosystemAdapter {
  async createClientWithProvider(provider: KeyProvider): Promise<EcosystemClient> {
    const account = provider.getAccount();
    if (!account) {
      throw new Error("No account available");
    }

    // Get address for this ecosystem
    const address = await account.getAddress(this.ecosystemType, chainId);

    // Get signers for transaction signing
    const signers = account.getSigners();

    return new MyClient(address, signers);
  }
}
```
