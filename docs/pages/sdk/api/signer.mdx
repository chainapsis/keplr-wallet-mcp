# Signer API

Interface for cryptographic signing primitives.

## Import

```typescript
import { Signer, CurveType, SignatureResult } from "@keplr-wallet/keplr-wallet-mcp/keys";
```

## Interface

```typescript
interface Signer {
  readonly curve: CurveType;
  getPublicKey(): Uint8Array;
  signHash(hash: Uint8Array): Promise<SignatureResult>;
}
```

## Types

```typescript
type CurveType = "secp256k1";

interface SignatureResult {
  r: Uint8Array;
  s: Uint8Array;
  v?: number;
}
```

## Properties

### `curve`

```typescript
readonly curve: CurveType;
```

The elliptic curve used by this signer.

| Curve | Usage |
|-------|-------|
| `secp256k1` | Cosmos chains |

## Methods

### `getPublicKey`

```typescript
getPublicKey(): Uint8Array;
```

Get the public key bytes.

**Returns:** Public key as `Uint8Array`

**Format:**
- `secp256k1`: 33 bytes (compressed) or 65 bytes (uncompressed)

### `signHash`

```typescript
signHash(hash: Uint8Array): Promise<SignatureResult>;
```

Sign a hash.

**Parameters:**
- `hash` - 32-byte hash to sign

**Returns:** Signature components

## DerivableSigner Interface

```typescript
interface DerivableSigner extends Signer {
```

## Built-in Implementations

### Secp256k1Signer

```typescript
import { Secp256k1Signer } from "@keplr-wallet/keplr-wallet-mcp/keys/signers";

// From mnemonic
const signer = Secp256k1Signer.fromMnemonic(mnemonic, path);

// From private key
const signer = new Secp256k1Signer(privateKey);
```

Features:
- BIP32/BIP44 derivation
- Cosmos compatible
- Low-S normalization

## Example Implementation

```typescript
import { Signer, CurveType, SignatureResult } from "@keplr-wallet/keplr-wallet-mcp/keys";

class CloudKmsSigner implements Signer {
  readonly curve: CurveType = "secp256k1";

  constructor(
    private client: KmsClient,
    private keyId: string
  ) {}

  getPublicKey(): Uint8Array {
    return this.client.getPublicKeySync(this.keyId);
  }

  async signHash(hash: Uint8Array): Promise<SignatureResult> {
    // Request signature from KMS
    const sig = await this.client.sign(this.keyId, hash);

    // Normalize low-S if needed
    const normalizedS = this.normalizeLowS(sig.s);

    return {
      r: sig.r,
      s: normalizedS,
      v: sig.v,
    };
  }

  private normalizeLowS(s: Uint8Array): Uint8Array {

  }
}
```

## Signature Normalization

### Low-S Requirement

Some Cosmos protocols require the S value to be in the lower half of the curve order:

```typescript
const CURVE_ORDER = BigInt("0xFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFEBAAEDCE6AF48A03BBFD25E8CD0364141");
const HALF_ORDER = CURVE_ORDER / 2n;

function normalizeLowS(s: bigint): bigint {
  if (s > HALF_ORDER) {
    return CURVE_ORDER - s;
  }
  return s;
}
```
