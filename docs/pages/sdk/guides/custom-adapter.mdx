# Custom Adapter Development

Build an ecosystem adapter for a new blockchain.

## Overview

EcosystemAdapters provide:
- Chain connectivity
- Address derivation
- Transaction signing
- MCP tool registration

## Interface

```typescript
interface EcosystemAdapter {
  readonly ecosystemType: EcosystemType;

  isSupported(provider: KeyProvider): boolean;

  createClientWithProvider(
    provider: KeyProvider
  ): Promise<EcosystemClient> | EcosystemClient;

  registerTools(server: McpServer, store: KeplrStore): void;
  registerResources?(server: McpServer, store: KeplrStore): void;
  registerPrompts?(server: McpServer, store: KeplrStore): void;
}
```

## Step-by-Step

### 1. Define Ecosystem Type

Add to shared types (or use as custom type):

```typescript
type EcosystemType = "cosmos" | "mychain";
```

### 2. Create Adapter Class

```typescript
import {
  EcosystemAdapter,
  EcosystemClient,
  EcosystemType,
} from "@keplr-wallet/keplr-wallet-mcp/ecosystem";
import type { KeyProvider } from "@keplr-wallet/keplr-wallet-mcp/keys";
import type { McpServer } from "@modelcontextprotocol/sdk/server/mcp.js";
import type { KeplrStore } from "@keplr-wallet/keplr-wallet-mcp/store";

export class MyChainAdapter implements EcosystemAdapter {
  readonly ecosystemType: EcosystemType = "mychain" as EcosystemType;

  isSupported(provider: KeyProvider): boolean {
    // Check if key provider supports this ecosystem
    return provider.getSupportedEcosystems().includes(this.ecosystemType);
  }

  async createClientWithProvider(
    provider: KeyProvider
  ): Promise<EcosystemClient> {
    // Create client instance
    return new MyChainClient(provider);
  }

  registerTools(server: McpServer, store: KeplrStore): void {
    this.registerQueryTools(server, store);
    this.registerTransactionTools(server, store);
  }

  private registerQueryTools(server: McpServer, store: KeplrStore): void {
    // Query tools
  }

  private registerTransactionTools(server: McpServer, store: KeplrStore): void {
    // Transaction tools
  }
}
```

### 3. Implement Client

```typescript
import { EcosystemClient } from "@keplr-wallet/keplr-wallet-mcp/ecosystem";
import type { KeyProvider } from "@keplr-wallet/keplr-wallet-mcp/keys";

export class MyChainClient implements EcosystemClient {
  constructor(private provider: KeyProvider) {}

  async getAddress(chainId: string): Promise<string> {
    const account = this.provider.getAccount();
    if (!account) throw new Error("No account");

    // Derive address for chain
    return this.deriveAddress(account, chainId);
  }

  async signTransaction(tx: any): Promise<any> {
    const account = this.provider.getAccount();
    if (!account) throw new Error("No account");

    const signer = account.getSigners()[0];
    // Sign with appropriate method
    return signer.signHash(tx.hash);
  }

}
```

### 4. Register Tools

```typescript
private registerQueryTools(server: McpServer, store: KeplrStore): void {
  server.registerTool(
    "mychain-get-balance",
    {
      description: "Get balance on MyChain",
      inputSchema: {
        chainId: z.string().describe("Chain ID"),
        address: z.string().optional().describe("Address (default: active wallet)"),
      },
      annotations: { readOnlyHint: true },
    },
    async ({ chainId, address }) => {
      const client = await store.getClientFor("mychain", chainId);
      const addr = address || await client.getAddress(chainId);

      const balance = await this.fetchBalance(addr, chainId);

      return {
        content: [{
          type: "text",
          text: JSON.stringify({
            chainId,
            address: addr,
            balance,
            suggestedActions: [
              { tool: "mychain-send", reason: "Send tokens", priority: 1 }
            ]
          }, null, 2)
        }]
      };
    }
  );
}
```

### 5. Export Factory

```typescript
// index.ts
export { MyChainAdapter } from "./adapter.js";
export { MyChainClient } from "./client.js";

// Default export must be factory function
export default () => new MyChainAdapter();
```

## Registration

### Via optionalDependencies

Add to server's `package.json`:

```json
{
  "optionalDependencies": {
    "@keplr-wallet/adapter-mychain": "workspace:*"
  }
}
```

### Via Environment

```bash
KEPLR_ADAPTERS="@keplr-wallet/adapter-mychain"
```

## Best Practices

### Error Handling

```typescript
import { classifyError, isSetupRequiredError, createSetupRequiredResponse } from "@keplr-wallet/keplr-wallet-mcp/errors";

async ({ chainId }) => {
  try {
    // Operation
  } catch (error) {
    if (isSetupRequiredError(error.message)) {
      return createSetupRequiredResponse({ attemptedAction: "mychain-get-balance" });
    }
    throw error;
  }
}
```
