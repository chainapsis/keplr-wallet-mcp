# Tutorial: Cross-Chain Transfer

Transfer tokens between Cosmos chains using IBC.

## Prerequisites

- Wallet with tokens on a Cosmos chain
- Both source and destination chains supported

## Scenario

Transfer 50 ATOM from **Cosmos Hub** to **Osmosis** for trading.

## Step 1: Check Source Balance

Verify you have tokens to transfer:

```
User: Show my ATOM balance on Cosmos Hub
```

**Response:**

```json
{
  "chain": "cosmoshub-4",
  "balances": [
    { "formatted": "150 ATOM" }
  ]
}
```

## Step 2: Check IBC Channel (Optional)

See available IBC routes:

```
User: Show IBC channels from Cosmos Hub to Osmosis
```

**Response:**

```json
{
  "channels": [
    {
      "channelId": "channel-0",
      "destination": "osmosis-1",
      "state": "open"
    }
  ]
}
```

## Step 3: Initiate Transfer

Request the IBC transfer:

```
User: Send 50 ATOM from Cosmos Hub to Osmosis
```

**Preview:**

```json
{
  "status": "pending_confirmation",
  "preview": {
    "summary": "IBC transfer 50 ATOM to Osmosis",
    "route": {
      "source": "cosmoshub-4",
      "destination": "osmosis-1",
      "channel": "channel-0"
    },
    "from": "cosmos1sender...",
    "to": "osmo1sender...",
    "amount": "50 ATOM",
    "estimatedFee": "0.01 ATOM",
    "estimatedTime": "~30 seconds"
  }
}
```

## Step 4: Confirm Transfer

```
User: Yes, confirm the transfer
```

**Success:**

```json
{
  "status": "success",
  "txHash": "ABC123...",
  "explorerUrl": "https://mintscan.io/cosmos/txs/ABC123",
  "transfer": {
    "amount": "50 ATOM",
    "destination": "osmosis-1",
    "estimatedArrival": "~30 seconds"
  }
}
```

## Step 5: Verify on Destination

Wait ~30 seconds, then check Osmosis:

```
User: Show my balance on Osmosis
```

**Response:**

```json
{
  "chain": "osmosis-1",
  "balances": [
    { "formatted": "100 OSMO" },
    { "formatted": "50 ATOM (IBC)" }
  ]
}
```

Your ATOM has arrived as an IBC token.

## Transferring Back

To return ATOM to Cosmos Hub:

```
User: Send my ATOM from Osmosis back to Cosmos Hub
```

The tokens will be "unwrapped" back to native ATOM.

## Understanding IBC Tokens

### On Source Chain

```
50 ATOM (native)
```

### On Destination Chain

```
50 ATOM (IBC)
denom: ibc/27394FB092D2EC...
```

The IBC denom is a hash representing the token path. Keplr Wallet MCP displays the friendly name.

## Multi-Hop Transfers

Some routes require multiple hops:

```
User: Send USDC from Noble to Cosmos Hub
```

This might go: Noble → Osmosis → Cosmos Hub

The system handles routing automatically.

## Common Routes

| From | To | Use Case |
|------|-----|----------|
| Cosmos Hub | Osmosis | Trade ATOM |
| Noble | Osmosis | Use USDC for trading |
| Osmosis | Celestia | Participate in TIA |
| Cosmos Hub | dYdX | Perpetual trading |

## Troubleshooting

### Transfer Not Arriving

1. **Check source tx**: Verify it succeeded
2. **Wait longer**: Can take 1-2 minutes
3. **Check relayer**: May be delayed

```
User: Check status of transaction ABC123... on Cosmos Hub
```

### Wrong Destination Address

If you sent to a different recipient:

```
User: Send 50 ATOM from Cosmos Hub to osmo1recipient... on Osmosis
```

By default, tokens go to your own address on the destination.
