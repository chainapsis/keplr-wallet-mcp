# Tutorial: DeFi Basics

Learn to swap tokens on Osmosis DEX.

## Prerequisites

- Wallet with OSMO balance on Osmosis
- Keplr Wallet MCP configured

## Scenario

Swap 50 OSMO for ATOM on Osmosis DEX.

## Step 1: Check Your Balance

Start by checking what you have:

```
User: Show my balance on Osmosis
```

**Response:**

```json
{
  "chain": "osmosis-1",
  "balances": [
    { "formatted": "100 OSMO" }
  ],
  "suggestedActions": [
    { "tool": "osmosis-quote", "reason": "Get swap quote" }
  ]
}
```

## Step 2: Get a Quote

See the exchange rate before committing:

```
User: How much ATOM can I get for 50 OSMO?
```

**Response:**

```json
{
  "quote": {
    "tokenIn": {
      "amount": "50 OSMO",
      "valueUsd": "$40.00"
    },
    "tokenOut": {
      "amount": "~4.25 ATOM",
      "valueUsd": "$42.50"
    },
    "exchangeRate": "1 OSMO = 0.085 ATOM",
    "priceImpact": "0.08%"
  },
  "fees": {
    "swapFee": "0.2%",
    "networkFee": "~0.01 OSMO"
  },
  "minimumReceived": "4.21 ATOM"
}
```

### Understanding the Quote

| Field | Meaning |
|-------|---------|
| Exchange Rate | How much you get per token |
| Price Impact | How your trade affects price |
| Swap Fee | DEX trading fee |
| Minimum Received | Guaranteed amount (slippage protection) |

## Step 3: Execute the Swap

If the rate looks good, proceed:

```
User: Swap 50 OSMO for ATOM on Osmosis
```

**Preview:**

```json
{
  "status": "pending_confirmation",
  "preview": {
    "summary": "Swap 50 OSMO for ~4.25 ATOM",
    "tokenIn": "50 OSMO ($40)",
    "tokenOut": "~4.25 ATOM ($42.50)",
    "minimumReceived": "4.21 ATOM",
    "fees": {
      "swap": "0.1 OSMO",
      "network": "0.01 OSMO"
    },
    "slippage": "1%"
  }
}
```

## Step 4: Confirm

Review and confirm:

```
User: Yes, execute the swap
```

**Success:**

  "result": {

    "tokenOut": {

## Step 5: Verify Balance

Check your new balance:

```
User: Show my balance on Osmosis
```

**Response:**

```json
{
  "balances": [
    { "formatted": "49.89 OSMO" },
    { "formatted": "4.27 ATOM (IBC)" }
  ]
}
```

You now have ATOM on Osmosis!

## Understanding Slippage

### What is Slippage?

The price can change between quote and execution. Slippage tolerance is your acceptable difference.

### Adjusting Slippage

For volatile markets, increase slippage:

```
User: Swap 100 OSMO for ATOM with 2% slippage
```

### Slippage Guidelines

| Pair Type | Recommended |
|-----------|-------------|
| Major pairs (OSMO/ATOM) | 0.5-1% |
| Volatile tokens | 1-3% |
| Low liquidity | 3-5% |

## Tips

### Best Times to Trade

- Lower gas during off-peak hours
- Better rates when market is stable

### Check Before Large Trades

Always quote large amounts first:

```
User: Quote 1000 OSMO to ATOM
// Check price impact
// Then execute if acceptable
```

### Failed Transactions

If a swap fails with "slippage exceeded":
1. Price moved too much
2. Increase slippage or wait
3. Try smaller amount
