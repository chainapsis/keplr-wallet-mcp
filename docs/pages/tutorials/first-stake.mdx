# Tutorial: First Staking

Learn to stake your ATOM and earn rewards.

## Prerequisites

- Wallet with ATOM balance on Cosmos Hub
- Keplr Wallet MCP configured

## Step 1: Check Your Balance

Start by checking your available ATOM:

```
User: Show my ATOM balance on Cosmos Hub
```

**Expected Response:**

```json
{
  "chain": "cosmoshub-4",
  "balances": [
    {
      "denom": "uatom",
      "formatted": "150.5 ATOM"
    }
  ],
  "suggestedActions": [
    { "tool": "delegate", "reason": "Stake tokens to earn rewards" }
  ]
}
```

## Step 2: Explore Validators

Before staking, research validators:

```
User: Show me the top validators on Cosmos Hub
```

**What to Look For:**

| Factor | Good | Avoid |
|--------|------|-------|
| Commission | 5-10% | over 20% |
| Uptime | 99%+ | under 95% |
| Voting Power | under 5% | over 10% (centralization) |
| Jailed | No | Yes |

**Example Response:**

```json
{
  "validators": [
    {
      "name": "Validator A",
      "operatorAddress": "cosmosvaloper1abc...", // example dummy address
      "commission": "10%",
      "votingPower": "5.2%",
      "uptime": "99.9%"
    },
    {
      "name": "Validator B",
      "operatorAddress": "cosmosvaloper1def...", // example dummy address
      "commission": "8%",
      "votingPower": "4.1%"
    }
  ]
}
```

## Step 3: Stake Your ATOM

Choose a validator and stake:

```
User: Stake 100 ATOM to Validator A on Cosmos Hub
```

**Preview:**

```json
{
  "status": "pending_confirmation",
  "preview": {
    "summary": "Stake 100 ATOM to Validator A",
    "validator": {
      "name": "Validator A",
      "commission": "10%",
      "expectedAPY": "~15%"
    },
    "amount": "100 ATOM",
    "estimatedFee": "0.02 ATOM",
    "note": "Tokens will be locked. Unstaking takes 21 days."
  }
}
```

## Step 4: Confirm Transaction

Review the preview and confirm:

```
User: Yes, confirm the staking
```

**Success Response:**

```json
{
  "status": "success",
  "txHash": "ABC123...",
  "explorerUrl": "https://mintscan.io/cosmos/txs/ABC123",
  "staked": {
    "validator": "Validator A",
    "amount": "100 ATOM"
  }
}
```

## Step 5: Verify Your Stake

Check your staking info:

```
User: Show my staking info on Cosmos Hub
```

**Response:**

```json
{
  "totalDelegated": "100 ATOM",
  "totalRewards": "0 ATOM",
  "delegations": [
    {
      "validator": "Validator A",
      "amount": "100 ATOM",
      "rewards": "0 ATOM"
    }
  ]
}
```

## Step 6: Claim Rewards (Later)

After some time, you'll accumulate rewards:

```
User: Show my staking rewards
```

```json
{
  "totalRewards": "2.5 ATOM",
  "delegations": [
    {
      "validator": "Validator A",
      "rewards": "2.5 ATOM"
    }
  ]
}
```

Claim them:

```
User: Claim all my staking rewards on Cosmos Hub
```

## What You've Learned

1. **Checking balance** before staking
2. **Researching validators** for good staking
3. **Delegating tokens** to earn rewards
4. **Confirming transactions** for safety
5. **Claiming rewards** when they accumulate

## Tips

### Diversify

Spread your stake across 2-3 validators:

```
User: Stake 50 ATOM to Validator A and 50 ATOM to Validator B
```

### Compound Rewards

Re-stake your rewards for compound growth:

```
User: Claim my rewards and stake them to Validator A
```

### Monitor Commission Changes

Validators can change commission. Check periodically:

```
User: Show the commission for my validators
```
